# Ghost FTP Android parity

Ghost FTP Android must follow the same product identity as the Windows and Linux app while using a mobile-first native layout.

## Identity contract

- Product name: Ghost FTP
- Brand owner label: Brendigo
- Version: 2.1.1-rc.21
- Display version: 2.1.1 RC21
- Badge: RC21
- Build: 2026.09.24.21

## Interface contract

Android should keep the same primary product model as the desktop app:

- One application surface.
- Connection-first workflow.
- FTP, explicit FTPS and SFTP protocol choices.
- Remote workspace.
- Transfer queue.
- Settings and privacy messaging inside the same app surface.
- Clear disconnect behavior.
- No account requirement.
- No telemetry requirement.

## Mobile layout rules

- Prioritize one-handed use.
- Keep Connect, Disconnect and Refresh visible in the connection card.
- Avoid desktop-only window concepts in Android copy.
- Keep server, queue and privacy state visible without modal clutter.
- Do not persist passwords in ordinary app storage.

## Release blockers

An Android APK or AAB must not be published until all of the following are true:

- Android native build passes.
- Android UI review confirms the mobile layout matches the Ghost FTP product identity.
- FTP, explicit FTPS and SFTP protocol acceptance passes on Android.
- SFTP host-key handling is reviewed.
- Android release artifacts and checksums are generated by a dedicated release workflow.
- Documentation clearly separates Android artifacts from Windows and Linux artifacts.
