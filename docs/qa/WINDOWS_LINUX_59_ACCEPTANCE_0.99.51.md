## Evidence required for each screen

1. Install the exact-source package on the actual target OS. Record source SHA, package SHA-256, OS, desktop DPI, viewport, locale, theme and runtime/authentication state.
2. Capture genuine application pixels in that state, and compare using tools/qa/compare_reference_v8.py against the original SHA-256-pinned concept reference archive.
3. Record per-screen changed RGBA pixel count, ratio and mean error, inspect spacing, fonts, icon geometry, focus/keyboard and responsive layouts, then fix the highest observed deviations.
4. Mark acceptance only after a real capture, repeatable diff measurement, interactive tests and human signoff; do not alter real user data or disable security to imitate sample screens.

**Historical baseline (not current):** earlier Sync screenshot comparisons measured 97.21% changed Windows pixels and 96.55% changed Linux pixels; see docs/qa/PHASE3_REAL_WINDOWS_LINUX_SYNC_V0_99_19_2026_10_29.md. New percentages cannot be stated without fresh matched-state captures.

**Independent open acceptance:** live authorized cloud-provider flows, credential-vault recovery, high-concurrency transfer endurance, accessibility on target desktops, real package signing and complete 59/59 visual review.
