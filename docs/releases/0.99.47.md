## Safer file and server management

- Keep Sites delete confirmations open until the actual native profile/credential removal completes, pinned to the original saved site ID so a refreshed list cannot retarget the deletion. On failure, keep the modal open and show a retryable error.
- Apply the same awaited-confirmation busy state to Find Duplicates, Disk Usage and Snippets deletion.
- Prevent parent Escape from closing Find Duplicates during confirmation or an active deletion.
- Add ongoing code-contract regressions for these destructive operations without changing the backend's authority.

## Correct Preview classification, preserving release integrity

- Add explicit `workflow_dispatch` to the existing immutable Preview metadata workflow. A trusted maintainer can now re-run checksum-pinned metadata repair from the GitHub Actions UI if an external edit changes `prerelease` after the scheduled checks.
- Preserve the exact previously published tag commit, 21 asset IDs/names/sizes/SHA-256 digests and release bytes. Never call metadata repair a stable signing or notarization service.
- Add a regression test for manually triggered classification recovery.

## Retire the discontinued desktop platform

- Remove both legacy SwiftUI and shared Tauri platform-specific application sources and 3 dedicated workflows; delete obsolete installation material and shortcut tests.
- Remove discontinued-platform artifacts from the canonical release inventory and release workflow. Required distribution now contains **15 Windows/Linux and source/checksum assets**, with a separate all-or-nothing group of 4 signed-updater assets.
- Keep immutable historical tags, release archives and their SHA-256 evidence unchanged.
- Align runtime window styling, keyboard shortcuts, Rust local-file behavior and quality/dead-code/security audit contracts to the supported desktop platforms.
