# Ghost FTP by Brendigo — v0.99.76 Preview

**Development source:** 22 November 2026. **Previous published version:** [v0.99.75](https://github.com/bren-wp/Ghost-FTP/releases/tag/v0.99.75).
**Publication status:** unpublished development candidate; do not describe this version as released until the GitHub Release and its packages actually exist.

## Reliability and regression testing
- Fix the concurrent real-network FTP/FTPS/SFTP test runner: one failed worker no longer drops the Tokio JoinSet, aborting still-active sibling transfers.
- Drain all started worker tasks before returning the first failure, preserving its original cause and ensuring no unexamined worker result is silently interpreted as success.
- Add a deterministic Tokio regression that deliberately fails one worker and verifies both healthy siblings complete and all tasks are drained before error reporting.
- Retain the 1/4/8-session real localhost SHA-256 and exact-length transfer matrix, plus opt-in 4-GiB+ network testing on a dedicated disposable host.

## Limits and acceptance
- The change improves network-test fidelity, **not** production transfer protocol code. It does not establish uninterrupted behavior on external servers, physical >4-GiB integrity, actual Windows/Linux credential-vault reconnection, or 1:1 pixel-perfect native UI.
- Require exact-PR and exact-merged-main Rust/Clippy, quality, Windows hardening, real protocol E2E and Windows/Linux native packaging before any publication.
- Publish the next immutable Preview only with verified Windows Portable/Setup/MSI, Linux AppImage/DEB/RPM, source/documentation archives and SHA-256 artifact inventory.
- Signed Stable distribution, legal acceptance, external authenticated cloud-provider integrations and real desktop reference comparisons remain separately pending.
