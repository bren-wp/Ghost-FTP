# Ghost FTP 0.99.38 — safer Windows/Linux transfers and reliable release publication (Preview)

**Predecessor:** [v0.99.37](https://github.com/bren-wp/Ghost-FTP/releases/tag/v0.99.37) — public, 21 SHA-256-verified desktop artifacts.

## What's improved

- Windows/Linux Transfer Center excludes invalid, non-finite and future timestamps from the **last hour/day** filters. The unfiltered history remains accessible for troubleshooting. Boundary handling remains inclusive.
- Fixed a proven release blocker: stage directories (for example `dist/macos` and `dist/native`) were incorrectly passed to `sha256sum` during the final digest verification loop. Both upload and verification loops now accept only non-symlink regular files.
- Added a regression gate simulating desktop staging folders, a real package file and a symlink pointing into private staging material. Upload selection excludes the last two.
- The existing GitHub release pipeline continues to validate exact source SHA, all remote SHA-256 digests, complete asset inventory and immutable public Git tags; it does not overwrite older releases.
- Real Windows/Linux application screenshots and brand marketing remain in the README, with their original older-build source provenance. No generated screenshots are substituted.

## Build targets

Windows: Portable EXE, Setup EXE, MSI. Linux: executable, AppImage, DEB, RPM. macOS maintained independently. Android remains removed.

**Acceptance:** exact-commit TypeScript/React, Rust/Clippy, Go, FTP/FTPS/SFTP E2E, Windows/Linux native package builds, Windows hardening, macOS build, source audits, and SHA-256 package verification. This Preview does not certify live cloud tenants, every supported remote server, physical-device installation, code signing or 0% visual deviation.
