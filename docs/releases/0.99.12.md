# Ghost FTP 0.99.12 — Responsive and secure Android local search (development Preview)

**Previous public version:** v0.99.11. **Active development:** 0.99.12. Android versionCode: 990012.

## Improved
- Local-only Android search no longer blocks the UI thread. Search visits at most 1000 private storage entries, returns at most 150 results and recurses at most four directory levels using bounded DirectoryStream traversal.
- Symlinks and off-root paths are never searched; unreadable paths fail closed. Old searches cannot overwrite results after the user navigates or changes filters. No users' FTP credentials or real remote files are altered.
- Android toolbar restores its actual Back/Menu state regardless of UI language. Search scope selection now visually tracks the chosen Remote or Local tab with minimum 48dp touch surfaces.
- Four additional messages across 24 language resources with parity checks. New tests cover path safety, bounded scanning, cancellation and real navigation.

## Gate and remaining work
- Full Android emulator, lint, JVM, Rust, FTP/FTPS/SFTP end-to-end, Windows/Linux installers, native Swift macOS, shared Apple Silicon/Intel macOS and all security CI gates must pass before merge/release.
- The 16 approved Android screens, 30 Windows screens and 29 Linux screens still require individual genuine runtime pixel comparisons. Do not claim complete 1:1 acceptance from source tests.
- Native macOS authenticated FTPS/SFTP issue #223 remains open. Production signing/notarization and 24-language linguistic QA remain separate prerequisites.
