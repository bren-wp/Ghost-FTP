# Ghost FTP 0.99.39 — release integrity and Preview metadata (Preview)

**Predecessor:** [v0.99.38](https://github.com/bren-wp/Ghost-FTP/releases/tag/v0.99.38), preserved as an immutable public release.

## Improvements

- Established a shared, version-independent release asset contract for Windows, Linux, maintained macOS Previews, source/documentation archives and SHA256SUMS. Android is not published.
- The post-release checker accepts exactly the 21 core assets, or all 21 plus the complete optional four-file signed updater group. It rejects duplicate, missing, extra, empty or partially uploaded assets.
- Before publication, validates every local release file and SHA-256 checksum, rejecting symlinked assets. After publication, downloads the real checksums file and verifies every GitHub release digest, file size and name against it.
- Expanded automated negative regression cases. The public release must be a genuine published Preview, not a Draft or unverified Stable edition.
- Preserved immutable source tags, historical assets, existing client protocols and desktop compatibility.

## Packages and verification boundaries

Windows: Portable EXE, NSIS Setup EXE and MSI. Linux: native binary, AppImage, DEB and RPM. Existing macOS Preview packages remain maintained. Android remains retired.

**Acceptance:** Only the actual successful exact-commit CI run can certify an individual build/test gate. Signing, manual OS installation and upgrade, real external FTP/cloud hosts and pixel-perfect acceptance of all 59 screens require separate evidence; none is implied by this release.
