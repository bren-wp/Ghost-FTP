# Ghost FTP 0.99.61 Preview — modular transfer safety and Agent Bridge hardening

**Publisher:** BRENDIGO · https://brendigo.com  
**Previous published edition:** v0.99.60 Preview  
**Channel:** Preview; this is not a certified signed Stable release.

## Improvements

- Isolated directory traversal and filename validation, transfer inventory limits and directory materialization in `ghostftp-desktop/src-tauri/src/transfer/path_safety.rs`.
- Made simultaneous recursive downloads tolerate a competing real-directory creation, but reject an existing symlink or file instead of following the path.
- Separated strict localhost HTTP request framing into `ghostftp-desktop/src-tauri/src/bridge/http_request.rs`, preserving the authenticated REST/MCP routes.
- Rejected malformed/ambiguous request lines and HTTP headers, lossily decoded headers, folded fields and non-decimal Content-Length values.
- Limited active localhost Agent Bridge handlers to 32; additional connections are closed instead of spawning unbounded tasks.
- Added focused regressions and updated repository-wide static security contracts for the new modules.
