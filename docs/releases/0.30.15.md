# Ghost FTP 0.30.15 — premium design parity, Android launch identity and release correction

This release candidate continues the **real Ghost FTP applications** based on the publicly released 0.30.14 source. It is not a claim of 75 completed pixel-identical screens.

## Actual application changes

- **Windows / Linux:** adjusts the live React/Tauri dark sidebar to the 214px width and 43px item rhythm from the supplied 1290×852 desktop reference, with responsive behaviour below 1100px and explicit accessible focus/disabled states. FTP, FTPS and SFTP implementations remain intact.
- **Android:** replaces the approximate hand-drawn Canvas ghost with the *exact approved vector drawable* already used for the app launcher; the same symbol now appears in the real navigation rail and header. Android 12–15 platform launch screens use the real logo and canonical navy background; privacy and secure window protections remain in place.
- **macOS:** refines the functional SwiftUI new-connection action and brand lockup, updates workspace heading hierarchy, and reduces the minimum window from 1080×680 to 840×560 so smaller displays can use the app. Previous private 0600 FTP transfer staging hardening stays intact.
- **Reference QA:** adds a machine-readable 75-screen map (30 Windows, 29 Linux, 16 Android) with real source file pointers and an exact-head quality check that fails if a reference loses its implementing surface. These mappings have visual acceptance **pending** until real installed screenshots and interaction comparisons exist.
- **Release integrity:** moves source metadata forward to 0.30.15; the immutable published 0.30.14 tag is not retargeted. All six exact-HEAD gates must pass before merge/release.

## Explicit limitations

- The supplied reference archive has **no dedicated macOS mockups**.
- A matching design token, drawable or implementation pointer is **not** proof of 1:1 pixel parity across all screen sizes.
- macOS remains a non-notarized Preview. FTP browsing/upload/download is enabled, but macOS explicit FTPS and SFTP file operations must stay disabled until trusted TLS certificate/hostname checks and SSH host-key verification are complete.
- Android's separately labelled installable APK is a Preview; the production APK remains unsigned until distributor signing is configured. Production packages are identified by the release pipeline, not by mockups.

## Required evidence before publication

The same exact HEAD commit must pass **Ghost FTP quality**, **Ghost FTP protocol E2E**, **Ghost FTP native build**, **Ghost FTP Android**, **Validate Windows hardening**, and **Ghost FTP macOS**. After merging, repeat the six checks on `main`, validate installer and Preview package artifacts and publish only through the canonical versioned release workflow.
