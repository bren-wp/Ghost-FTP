# Ghost FTP 0.30.11

Release date: 6 October 2026

Ghost FTP 0.30.11 focuses on cross-platform shell parity, connection-health UX, profile backup safety and stronger dead-code enforcement.

## Main changes

- Gives the dedicated macOS client the same six-workspace information architecture as the Windows/Linux reference: Files, Sites, Transfers, Sync & Backup, Settings and Help & About, plus New connection in the persistent sidebar.
- Removes the separate macOS Settings scene so Settings stays inside the same persistent application window.
- Adds a credential-free macOS transfer ledger with upload/download/running/completed/failed/cancelled states and a bounded 200-record history.
- Adds real macOS site-profile backup/restore. Backup files contain connection metadata only; passwords remain in macOS Keychain and are never serialized.
- Fixes macOS transfer-status and save-panel interpolation so real file names are shown instead of literal placeholder text.
- Adds macOS tests for profile-backup round trips, merge behavior, transfer-history persistence and the bounded history limit.
- Adds a macOS private Swift declaration audit alongside the existing compiler/test/build gates.
- Bounds macOS profile-backup restore reads to 256 KiB and converts persisted in-progress transfers to Cancelled after an application restart instead of leaving stale activity forever.
- Adds Android Sync & Backup to the primary navigation rail so the Android shell matches the Windows workspace model.
- Adds real Android connection-settings export/restore through the system document picker with a 256 KiB input bound, schema validation and no password field.
- Restoring Android connection settings terminates the previous authenticated session and requires the user to enter the password again.
- Extends Android emulator smoke coverage to click through the Sync & Backup workspace.
- Adds Windows/Linux connection-health state to the shared desktop status bar: Healthy, Checking and Needs attention.
- Runs desktop connection health every 30 seconds only while the app is visible, and also on focus; users can manually trigger a health check from the status bar.
- Keeps the existing single-flight SFTP reconnect/keep-alive implementation as the only reconnect engine rather than introducing duplicate transport state.
- Extends the desktop UI contract into a cross-platform parity gate covering the six workspaces on Windows/Linux, Android and macOS.
- Keeps TypeScript reachability/no-unused checks, Rust fmt/check/test/clippy, Android private Kotlin symbol audit and the new macOS private Swift symbol audit release-blocking.

## Platform status

### Windows / Linux

Windows and Linux continue to use the same Tauri/React/Rust product source. 0.30.11 adds visible connection-health UX and cross-platform shell parity checks without splitting the desktop code path.

### Android

Android retains real FTP, explicit FTPS and SFTP connection/listing/upload/download/new-folder/rename/delete workflows and adds a real Sync & Backup workspace for non-secret connection settings.

### macOS

The macOS client now uses the same primary workspace model as the desktop reference and keeps real plain-FTP listing/upload/download, profile management, transfer history, settings and backup/restore in one persistent window.

Explicit FTPS and SFTP file-operation engines on macOS remain gated until real TLS certificate/hostname verification and SSH host-key verification are implemented. The macOS artifact remains an ad-hoc-signed development Preview rather than a Developer ID signed/notarized production package.
