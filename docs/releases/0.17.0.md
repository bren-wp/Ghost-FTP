# Ghost FTP 0.17.0

Release status: development preview

Release date: 27 September 2026

0.17.0 is the next development cycle after 0.16.0. This version accompanies real release-system hardening and the completed canonical public-history migration; it is not a version-only change.

## Changes

- Public legacy RC releases were migrated and verified as v0.1.0 through v0.14.0.
- Obsolete RC15–RC23 release automation and approval markers were retired.
- Duplicate workflow_run events for the same source SHA are deduplicated before the expensive release publish job.
- Exact-SHA quality, protocol, Android and Windows hardening gates remain mandatory.
- Publication remains sequential: v0.17.0 waits for v0.16.0 to exist first.
