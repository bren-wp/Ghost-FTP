# Ghost FTP 0.17.0

Release status: **published**

Release date: 27 September 2026

0.17.0 continued the canonical pre-1.0 release train after 0.16.0.

## Changes

- Completed and verified the canonical public-history migration.
- Kept `version.json` as the single active product version source.
- Hardened Windows background helper processes against unintended console-window flashes.
- Replaced shell-based PATH discovery with direct PATH scanning.
- Added no-console helper regression tests and CI coverage.
- Made Android validation run on every pull request to `main`.
- Kept committed `Cargo.lock` validation with `--locked`.
- Updated version progression policy so meaningful fixes could remain within an active development cycle without forcing a version-only bump.
- Published normalized Windows, Linux, Android, source, website, updates, documentation and SHA-256 assets.

## Release integrity

The canonical `v0.17.0` tag is immutable. GitHub Releases is the authoritative source for its published asset set and digests.

0.17.0 remains a pre-1.0 release and is not a stable/FINAL claim.
