# Ghost FTP 0.17.0

Release status: **development preview — not yet published**

Development date: 27 September 2026

0.17.0 is the active development cycle after published 0.16.0. It contains real hardening and release/documentation work; it is not a version-only change.

## Changes

- Completed/verified the canonical public-history migration.
- Kept `version.json` as the single active product version source.
- Retired obsolete legacy release/backfill automation from the active workflow surface.
- Hardened Windows background helper processes against unintended console-window flashes.
- Replaced shell-based PATH discovery with direct PATH scanning.
- Added no-console helper regression tests/CI coverage.
- Made the Android gate run on every pull request to `main`.
- Kept committed `Cargo.lock` validation with `--locked` in native CI.
- Updated version progression policy so meaningful fixes can remain within the active 0.17.0 cycle.
- Synchronized active documentation to canonical `0.x` versions, actual source paths, workflow names and published-release state.

## Required evidence before publication

The exact source intended for `v0.17.0` must pass:

- Ghost FTP quality
- Ghost FTP protocol E2E
- Ghost FTP native preview build
- Ghost FTP native build
- Ghost FTP Android
- Validate Windows hardening

The canonical release workflow must then package/verify the Windows, Linux, Android, source, documentation and SHA-256 assets at the exact release source SHA.

## Stable status

Publication of `0.17.0` would still be a pre-1.0 development release. Stable/FINAL promotion remains subject to the documented target-OS lifecycle, visual, security, accessibility and signing acceptance.
