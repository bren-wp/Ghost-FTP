# Ghost FTP 0.99.70 Preview — fail-closed npm security reporting

**Status:** Development candidate; do not treat this document as evidence of publication. Previous canonical public release: [v0.99.69](https://github.com/bren-wp/Ghost-FTP/releases/tag/v0.99.69), published 17 November 2026.

## Changes
- Extract the npm development audit decision into a pure, independently testable policy module.
- Reject incomplete or error-bearing `npm audit --json` output rather than reporting a false clean bill of health.
- Reject high/critical audit entries without complete dependency paths, unknown advisory roots or dependencies not proven to be development-only.
- Remove the previous implicit allowance for a `braces` advisory without a corresponding locally verified fix.
- Add negative tests for unknown roots, untrusted dependency paths, missing lockfile nodes, runtime exposure and registry/audit failure.
- Keep exact-version local `picomatch` parser verification and bounded matcher tests, even if the advisory is withdrawn, until an independently verified replacement is accepted.
- Keep Windows/Linux Tauri, Rust, Go, transfer protocols, uploader and installed GUI unchanged in this scoped security iteration.

## Advisory status and limits (18 November 2026)
- GitHub advisory [GHSA-fc5q-39xc-vjpf](https://github.com/advisories/GHSA-fc5q-39xc-vjpf) was marked **withdrawn** on 18 November 2026; its withdrawal text does not prove published packages were patched.
- [GHSA-vfj7-8cjw-p6xm](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm) was withdrawn on 23 October 2026 with a statement that the described issue was not practically exploitable.
- This change does **not** claim formal vulnerability clearance, complete protocol-transfer integrity, signed Stable distribution, or physical 4+ GiB acceptance.
- The conditional picomatch exception must still be backed by the shipped local parser mitigation; new or unknown high/critical findings fail CI.

## Verification before publication
The exact current PR HEAD must pass the npm development policy tests, postinstall/parser regressions, `npm audit --omit=dev --audit-level=high`, the independent npm development audit, Rust workspace checks, frontend build, native Windows/Linux packaging, protocol E2E and Windows hardening.

Do not merge or publish if any required gate fails. Any new release requires verified nonempty Windows Portable/Setup/MSI, Linux AppImage/DEB/RPM, sources, SHA-256 digests and release metadata. Real-world hardware and multi-gigabyte transfer fault injection remain separately pending.
