# Ghost FTP 0.30.4

Release date: 4 October 2026

Ghost FTP 0.30.4 follows the published 0.30.3 release with another cross-platform interaction-safety pass for Windows, Linux and Android.

## Windows and Linux Agent Bridge hardening

- Agent Bridge master enable/disable, endpoint Start/Stop, per-session access and approval-policy changes now share a single mutation mutex.
- Rapid double-clicks or conflicting toggle changes cannot dispatch overlapping Bridge IPC mutations from the same panel.
- Bridge controls are disabled while a mutation is in flight and the endpoint Start/Stop control exposes an explicit busy state.
- Auto-approve and sudo policy controls stay mutually consistent while backend reconciliation is in progress.
- The interaction-hardening CI contract now requires the Agent Bridge mutex and disabled/busy wiring.

## Android transfer-state hardening

- Picking a new upload document is disabled while a transfer or remote mutation is in progress.
- Reset Transfers and Reset Connection are disabled while an operation is in flight so the visible form cannot diverge from the active transfer context.
- The Settings Disconnect control now mirrors real session state and is disabled when no authenticated session exists.
- The normal Disconnect path remains available during an active remote operation so the user can explicitly cancel the operation/session.
- Android instrumentation verifies disconnected Settings controls and local action availability.
- The Android production contract now locks the busy-sensitive local-action and session-disconnect trackers.
