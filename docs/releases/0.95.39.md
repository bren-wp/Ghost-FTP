# Ghost FTP v0.95.39 — Fail-closed WebDAV/HTTP directory listing (development preview)

Published predecessor: [v0.95.38](https://github.com/bren-wp/Ghost-FTP/releases/tag/v0.95.38).

## Changes in this pull request

- Reject truncated, malformed or incomplete WebDAV PROPFIND multistatus XML. A partial remote directory cannot silently become a successful inventory used for destructive synchronization.
- Require HTTP 207 Multi-Status for depth-one WebDAV listings and reject missing response hrefs, invalid XML roots and invalid response bodies.
- Propagate nginx HTTP JSON autoindex parse failures instead of interpreting malformed JSON as an empty directory. A valid empty array remains supported.
- Add regression tests for malformed input and preserve valid Nextcloud, Apache and nginx listing fixtures.
- Advance preview build metadata from the published immutable v0.95.38 tag without changing existing release assets or tags.
