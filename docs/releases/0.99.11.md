# Ghost FTP 0.99.11 — Native icon, 24-language splash and accessibility consistency (development Preview)

**Previous public edition:** v0.99.10. **Development source:** 0.99.11. **Channel:** Preview; production signing/notarization is not certified.

## Implemented

- Align Android in-app, system splash and adaptive launcher ghost silhouette and violet palette with the user-supplied Android visual reference while keeping the desktop's own approved cyan brand.
- Raise Android header Back/Add and standard action targets to at least 48 dp without expanding the 52 dp navigation bar; guard action availability and localized spoken descriptions.
- Translate six additional splash/brand/protocol accessibility strings across 24 advertised Android languages with resource parity and placeholder validation. Do not claim all native text is now translated.
- Strengthen desktop Windows/Linux PNG and ICO asset validation before packaging; run a new cross-platform source branding/geometry contract in Android and full-quality CI.
- Preserve user credentials, existing servers, saved profiles, encrypted transport safety and 0.99.10 improvements. Native macOS FTPS/SFTP support remains prohibited until issue #223 security acceptance.

## Required before release

- Exact-head Android lint, JVM tests, instrumented Android 16 real-view navigation, Windows/Linux Tauri installers, Swift native macOS, Intel/Apple Silicon macOS shared packages, protocol E2E, code/security audits, localization and source-version gates.
- Real 1:1 acceptance remains pending for 30 Windows, 29 Linux and 16 Android reference screens. No approved macOS screen references were supplied, and no concept image is inserted as runtime content.
- APK/AAB Play production upload credentials, Windows Authenticode and macOS Developer ID/notarization are separate requirements. Keep this edition marked Preview.
