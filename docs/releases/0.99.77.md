# Ghost FTP by Brendigo — 0.99.77 Preview

**Status:** [published Preview](https://github.com/bren-wp/Ghost-FTP/releases/tag/v0.99.77). Date: 22 November 2026.
**Previously published:** [v0.99.76](https://github.com/bren-wp/Ghost-FTP/releases/tag/v0.99.76).

## Live protocol reliability and fault injection

- Extend loopback FTP and explicit FTPS E2E: establish a disposable profile, stream a binary sentinel, reauthenticate the *same* session twice, verify original bytes after each reconnect, and ensure explicit Disconnect prevents all later operations and reconnection on that session ID.
- Open the same profile in a **new** authenticated session after Disconnect and verify that its session ID differs and the original remote bytes survived, before cleaning up the disposable fixture.
- Inject a deterministic source read failure after 96 KiB while uploading 2 MiB + 257 B into a unique staging sibling, reconnect the control channel, verify the existing final target is unchanged, remove the partial staging sibling if present, and assert no staging orphan remains. This is **not** a simulated physical network drop or process crash.
- Add a real, bounded-memory streamed upload/download SHA-256 matrix for **16 MiB + 17 B** on FTP, explicit FTPS, SFTP (Linux), and FTP (Windows). Retain the existing 1/4/8 workers at 1 MiB + 17 B and separately opt-in >4-GiB stress.

## Visual acceptance fail-closed comparison

- Add `--require-exact` to `tools/qa/compare-screen-references.py`. A one-channel change of 1 in any pixel now fails strict 1:1 evaluation, even when it remains below the existing visually meaningful change threshold of 12.
- Add tests proving exact equality, one-channel difference, missing screenshot and comparison-only reporting; run these on the native Linux build CI with Pillow.
- **No 59-screen 1:1 approval claimed:** the reference ZIP is illustrative artwork, and genuine Windows/Linux native captures at controlled DPI, locale and interaction states must be compared to user-approved references before recording any pass.

## Not yet verified

- Physical network cable/Wi-Fi loss, server power-cycle, large (>4 GiB) network transfers and disk-full recovery on real target machines.
- Windows 10/11 Credential Manager and Linux Secret Service persistence/reconnection across native logout/reboot.
- Authenticated external cloud accounts, OAuth expiry/revocation, provider 429/5xx behavior, quotas and upload session cleanup.
- Independent signed Stable release audit, legal review and 59/59 verified native screenshot parity.
