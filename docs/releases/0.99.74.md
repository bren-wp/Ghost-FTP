# Ghost FTP by Brendigo — 0.99.74 Preview

**Source date:** 21 November 2026 · **Distribution channel:** Preview

## Additional Windows network transfer verification

The Windows native protocol job now runs the existing real FTP upload/download integrity suite against a loopback-only test server. It exercises connection, multi-size upload/download verification, zero-byte and Unicode filenames, rename collision safety, listing, removal and failure behavior. Its result is required by the protocol security gate, in addition to Linux FTP/FTPS/SFTP and Windows local filesystem checks. **This change does not establish native Windows FTPS or SFTP network interoperability, cloud-provider credentials, or exhaustive user-interface functionality.** Those remain explicit follow-up acceptance requirements.

## Highlights

- Prevent repeat execution of confirmation and prompt actions caused by rapid double-click/Enter events before React can render the busy state.
- Consolidate the desktop confirmation dialog with the reusable file-ui dialog while preserving error toasts in the desktop app and inline error feedback for the shared component.
- Remove duplicate Escape handling from the file prompt and prevent implicit form submission.
- Hold the single-flight guard through successful dialog dismissal and release only on action failure, with additional source regression checks.
- Share the accessible focus-management hook between desktop workspaces and the file browser without changing keyboard-navigation policy.
- Remove two unused Tauri JavaScript dependencies (`@tauri-apps/plugin-fs` and `@tauri-apps/plugin-shell`) and their lockfile records, leaving needed native backend APIs untouched.
- Strengthen the Rust dead-code scanner for nested block comments, raw strings and quoted characters, including new regression fixtures.
- Extract the Agent Bridge's 400+ lines of Rust regression tests from `bridge.rs` into `bridge/tests.rs`, keeping the same tests linked into the same module.
- Report truthful HTTP status reason phrases (e.g., 404 Not Found and 502 Bad Gateway) instead of presenting failed Agent Bridge operations with an `OK` reason.
- Reject invalid, oversized and inconsistent base64 file replies from paired Agents instead of silently turning them into empty success responses; correct the Agent daemon read-file truncated flag for an exact-length file.
- Update source-level interaction regression checks.
- Correct the published v0.99.73 predecessor and align active documentation with v0.99.74 source.
- Improve the public README's presentation and historical native screenshot provenance.
- Keep the EULA/LICENSE distribution addendum consistent with the current source version and add a legal review checklist.
- Document required native Windows/Linux reference comparison and a narrowly scoped duplicate-code/dead-code audit.

## Compatibility and user data

No intentional changes were made to FTP/FTPS/SFTP wire protocols, connection profiles, credential storage, file-transfer persistence, remote path handling or updater verification. This source update is not evidence of identical runtime behavior on all servers or operating systems.
