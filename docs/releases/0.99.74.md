# Ghost FTP by Brendigo — 0.99.74 Preview

**Source date:** 21 November 2026 · **Distribution channel:** Preview

## Highlights

- Prevent repeat execution of confirmation and prompt actions caused by rapid double-click/Enter events before React can render the busy state.
- Consolidate the desktop confirmation dialog with the reusable file-ui dialog while preserving error toasts in the desktop app and inline error feedback for the shared component.
- Remove duplicate Escape handling from the file prompt and prevent implicit form submission.
- Update source-level interaction regression checks.
- Improve the public README's presentation and historical native screenshot provenance.
- Keep the EULA/LICENSE distribution addendum consistent with the current source version and add a legal review checklist.
- Document required native Windows/Linux reference comparison and a narrowly scoped duplicate-code/dead-code audit.

## Compatibility and user data

No intentional changes were made to FTP/FTPS/SFTP wire protocols, connection profiles, credential storage, file-transfer persistence, remote path handling or updater verification. This source update is not evidence of identical runtime behavior on all servers or operating systems.
