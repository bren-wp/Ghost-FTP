## Transfer Center reliability and performance

- File/folder selection is tied to the active session and profile; if either changes while the native picker is open, the upload is refused and the user receives an error instead of a transfer to the old connection.
- Native history-export save dialogs are inside the existing error boundary. Cancellation remains a no-op and backend failures remain visible.
- Recent history excludes invalid or negative timestamps and non-finite clear cutoffs; the unfiltered history remains available.
- Natural filename sorting extracts each basename once rather than splitting paths for each comparator call. Numeric and time sort values are also computed once. Stable ties and native record identity remain intact.
- Regression coverage includes 10,000 Windows/POSIX file names, malformed history and the native dialog guards.
