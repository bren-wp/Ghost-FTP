# Ghost FTP 0.99.41 — splash-free Windows/Linux startup (Preview)

**Predecessor:** v0.99.40. **Author:** Brendigo — https://brendigo.com.

## Changed

- Eliminated the full-window startup brand overlay, artificial 620 ms timer and unused React component/CSS. The real native Files workspace is displayed immediately; actual asynchronous settings, transfers, sync, notifications, deep links and updater initialization continue normally.
- Removed the retired splash from Tauri QA allow-lists, Windows and Linux screenshot pipelines and active Linux README gallery. Seven other genuine runtime views continue to be captured, and the old splash PNG is retained only as historical evidence.
- Corrected the default HTML language from zh-CN to en, consistent with English being the default UI language.
- Scheduled transfers re-evaluate due occurrences when the window becomes visible, receives focus, returns online or receives a pageshow event. Existing lastRunAt and in-flight guards prevent duplicate retries. The scheduler is local to the running application; it is NOT an OS background service.
- Added regression checks for the direct-launch contract, correct QA capture matrix, scheduling wake paths and cleanup.
