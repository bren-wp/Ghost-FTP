# Ghost FTP 2.1.1 RC16

Released for validation: 23 September 2026

RC16 focuses on simplifying Ghost FTP navigation and enforcing a true single-window desktop workflow.

## Main changes

- One persistent Ghost FTP window for the whole application.
- Files, Sites, Transfers, Sync & Backup, Cloud Storage, Settings and Help & About use the same main workspace.
- About, Help and Updates no longer create or imitate separate application windows.
- Terminal pop-out support was removed; the terminal remains docked in the main application window.
- The old multi-level top menu and duplicate navigation bars were removed.
- The main sidebar is intentionally compact and becomes icon-only at narrow widths.
- Language selection was removed from the main screen and is available only in Settings.
- File actions remain contextual: connect/site selection, refresh, upload, download, new folder, rename, delete and properties appear only in the Files workspace.
- New Connection and other short-lived tasks remain contained overlays inside the same native window.
- RC16 CI rejects secondary WebView application windows, browser popups/new tabs, duplicate header navigation and language controls outside Settings.

## Validation requirements

RC16 must pass frontend/UI/i18n checks, Rust fmt/check/tests/Clippy, real FTP/explicit-FTPS/SFTP E2E, Windows/Linux native builds and native Windows visual QA before publication.

RC15 remains an immutable published pre-release and is not retagged or replaced by this development line.
