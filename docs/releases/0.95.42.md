# Ghost FTP v0.95.42 — Guarded Android production upload-key signing (development preview)

Published predecessor: [v0.95.41](https://github.com/bren-wp/Ghost-FTP/releases/tag/v0.95.41). The predecessor tag is immutable; this is source-only Preview metadata.

## MOB-01 P0 partial implementation

- Protected GitHub environment `android-signing`, manual `workflow_dispatch` from main, explicit current commit confirmation and pinned expected upload certificate SHA-256.
- All six exact-main CI workflow families must pass before manual signing. The signing helper rejects missing identity, stale SHA, unexpected package, mismatched certificate or corrupt unsigned bundle, then locally verifies signed AAB and records non-secret provenance.
- Ordinary PR/public release builds remain unsigned for `com.ghostftp.android`; the separate `.preview` application ID continues using its independent preview signature.
- Synthetic negative Android CI checks cover absent identity, stale source SHA and malformed upload-certificate pin.
