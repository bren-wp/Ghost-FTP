# Ghost FTP 0.95.9 — signed-cloud peer filtering alignment (published 13 October 2026)

**Published:** [v0.95.9](https://github.com/bren-wp/Ghost-FTP/releases/tag/v0.95.9) from immutable source `de31ea3783f4b61069eda4db4e11078c96075415`, with 21 public release assets; predecessor `v0.95.8` remains unchanged.

## Implemented changes in this source candidate

- Block RFC 7343 ORCHIDv2 `2001:20::/28` IPv6 destinations in Android's actual OkHttp public-peer DNS selection and macOS's pinned-address curl selection. Reject either end of the /28 without weakening default TLS hostname/certificate validation.
- Regression coverage on both platforms for the newly excluded network range.
- Android SAF late registration during cancellation now schedules best-effort provider close on a daemon rather than running the provider's potentially blocked `close()` inline. JVM coverage of a deliberately blocked close does not replace device acceptance.
- Document exact 75-image premium concept coverage for Windows, Linux and Android and the separate real-capture QA gate. Concept images must never masquerade as actual production screenshots.
