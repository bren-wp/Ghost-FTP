# Ghost FTP 0.99.23 — native Windows Server Control Center and Windows-only Demo

Previous public edition: v0.99.22. This is a **development prerelease**, not a production-certified release. The user-facing release title is simply **Ghost FTP 0.99.23**; classification remains truthful until signing and acceptance gates are enforced.

## Changes

- Windows Ghost FTP Server now opens a native Windows Forms Control Center on double-click/no arguments, rather than immediately exiting from missing mandatory server configuration. An independent console-free Win32 GUI executable, Start Menu shortcut and installation/removal checks are required.
- The native Control Center uses real Windows Service Control Manager state, can Start/Stop a configured service with permission, does not display secrets and has a bounded, DPI-aware, responsive window instead of taking over the entire display. It uses no WebView; the older local-only HTTP dashboard remains optional.
- Linux Ghost FTP Server stays a headless native Go daemon with systemd service management and explicit private TLS credentials; no Linux graphical parity is claimed.
- Ghost FTP Demo is distributed exclusively as `GhostFTP-Demo-Windows-x64-Portable-v0.99.23.exe`, never Linux, macOS or an installer. It remains an isolated simulator, **not an identical Ghost FTP frontend**.
- Ghost CLI remains separately distributable as Windows portable and unsigned Setup, plus Linux binary, tar.gz, DEB and RPM, retaining real shared client protocol behavior.
- Require **39 real nonempty public artifacts with SHA-256 digests**, from a single immutable source SHA, plus complete Windows/Linux/Android/macOS quality and protocol gates. Historical public tag and artifacts are not rewritten.

## Not yet implemented or accepted

The graphical Ghost FTP Client is Tauri 2 (system WebView). Full WebView-free rewrite of the client, 1:1 native Linux Server GUI, exact Demo visual parity, full FTPS server account administration/RBAC, SFTP server, cross-device E2EE password sync, production signing/notarization and device-specific screenshot acceptance are outstanding. **Compilation alone does not establish complete functionality**. TLS, credentials and service provisioning remain securely opt-in.
