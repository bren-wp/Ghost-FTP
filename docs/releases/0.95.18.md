# Ghost FTP 0.95.18 — IIS LIST compatibility, fail-closed FTP inventory

## Implemented source behavior
- Recognize strict MS-DOS-style IIS FTP LIST rows for files and directories, including Unicode filenames and spaces, checked 64-bit file sizes and validated DOS date / 12-hour clock syntax.
- Continue parsing existing Unix LIST records. Reject unknown/malformed rows as an error instead of silently omitting remote files. Preserve safe rejection in recursive delete and existence/conflict probes.
- Tests for valid IIS file/directory, dot entries, leap days, overflow, invalid times, path separators and mixed-good/bad listings.
