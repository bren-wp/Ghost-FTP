# Ghost FTP 0.99.40 — late Preview metadata drift prevention (Preview)

**Predecessor:** [v0.99.39](https://github.com/bren-wp/Ghost-FTP/releases/tag/v0.99.39), whose 21 assets were published and verified; GitHub later showed `prerelease:false` even though post-release CI had previously seen `true`.

## Changes

- Add ongoing Preview metadata repair of the currently published and immediately previous desktop releases (including the historical 0.99.37 and 0.99.38 distributions), using immutable tag/source checks and complete remote SHA256SUMS validation before altering metadata.
- A separate validator mode accepts already-misclassified releases **only for metadata repair**. Strict publication verification continues to require `prerelease:true`; draft/incomplete releases are always rejected.
- Subscribe to externally edited/published GitHub release events, retain regular scheduled recovery and add a delayed second post-publication verification.
- Regression-test valid, missing, corrupted, draft and incorrectly classified release inventories.

## Distribution

Windows: portable EXE, Setup EXE and MSI. Linux: executable, AppImage, DEB and RPM. Existing macOS Preview packages remain included. No Android packages are published.

**Acceptance boundary:** Native builds, automated FTP/FTPS/SFTP integration and security gates must pass on the precise merge source. The patch does not claim production signatures, all real third-party servers/cloud integrations, successful installation on every device or verified 1:1 parity for 59 conceptual screens.
