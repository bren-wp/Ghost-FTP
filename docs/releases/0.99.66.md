# Ghost FTP 0.99.66 Preview — source candidate

**Published? No.** Previous published release is [v0.99.65](https://github.com/bren-wp/Ghost-FTP/releases/tag/v0.99.65). Candidate is [PR #294](https://github.com/bren-wp/Ghost-FTP/pull/294).

## Changes under review

- Every fresh SFTP staging file is created at byte zero with exclusive CREATE|EXCLUDE; paused and failed transfers no longer reuse progress from a different staging file.
- FTP/FTPS/SFTP upload promotion checks the local file's type, length, modification time and OS file identity on the open handle and source path, rejecting ordinary file swaps and edits.
- Ambiguous network errors no longer blindly replay cloud, Agent, WebDAV or SaaS mutating uploads. Manual retry remains possible.
- Source identity regression tests, documented live QA matrix for Windows/Linux, large and parallel transfers.

## Security and acceptance limits

These metadata checks are not cryptographic and cannot detect all simultaneous writes or forged timestamps. FTP RNTO collision races and server-specific overwrite semantics remain; partial remote staging may remain after failures. Windows/Linux credential-vault integration and 4+ GiB and concurrent checksum fault-injection tests are not yet certified.
