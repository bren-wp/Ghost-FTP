# Ghost FTP 0.99.35 — verified transfer resume for Windows and Linux (Preview)

**Published predecessor:** [v0.99.34](https://github.com/bren-wp/Ghost-FTP/releases/tag/v0.99.34). This Preview is under review until exact-SHA CI and release gates succeed; previous tags and assets remain immutable.

## Safer paused uploads and downloads

- SFTP now compares all previously committed bytes in the local and remote prefix before continuing a paused download or upload. An equal-length but altered file triggers a restart instead of a mixed-revision result.
- Ghost FTP Agent uses ranged daemon reads to confirm the entire committed prefix before resuming file transfers.
- FTP and explicit FTPS restart from zero when paused. REST/APPE + SIZE alone cannot establish that an unchanged remote prefix is present; this trades bandwidth for integrity.
- Added Rust same-size mismatch/short-prefix tests, static source integrity regression gates and an expanded [Windows/Linux protocol/security/dead-code review](../audits/WIN_LINUX_TRANSFER_RESUME_2026_11_07.md).

## Acceptance boundaries

Rust check/test/fmt, localhost FTP/FTPS/SFTP socket E2E, Windows/Linux native builds, release and dead-code/security checks must pass at this exact commit. Real external cloud-provider accounts and Windows/Linux pixel-for-pixel screenshot acceptance were not supplied, and production readiness or perfect cross-server compatibility is **not** certified by this source change.
