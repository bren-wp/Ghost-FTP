# Ghost FTP 0.30.17 — functional resource links and honest platform parity

Version 0.30.17 builds upon the published 0.30.16 source, without discarding previous premium design work or changing transfer protocol security.

## Delivered application changes

- **Windows/Linux React/Tauri:** Help/About offers working canonical GitHub locations for support issues, maintained project documentation, privacy policy and verified project releases. The reference-approved **More Than Transfer. Total Control.** tagline replaces legacy About copy. The separately configured trusted automatic-update service is unchanged.
- **Android Kotlin:** About uses the same official source, support, docs, privacy and EULA destinations via the existing exact HTTPS allowlist; no hidden browser redirects or telemetry.
- **macOS SwiftUI:** Help/About links target the maintained project sources. The information pane makes clear that FTP file operations are available while macOS FTPS/SFTP are disabled until certificate/hostname and SSH host-key verification are complete.
- **Quality contract:** adds an exact-source regression guard against reintroducing the retired web-host links or outdated wordmark slogans in these three real About surfaces.

## Known limitations

The ZIP supplies 75 Windows, Linux and Android static design mockups (30+29+16) but **no macOS UI mockups**. The existing 75-screen source traceability contract is not proof of installed-build visual parity. No 1:1 parity completion, notarization or secure macOS FTPS/SFTP implementation is claimed.

## Release gating

Publication is gated on all six required GitHub workflows passing at the same PR and merged main HEAD, with Windows and Linux installers, Android installable Preview, macOS Preview and archive checksums verified in the canonical release workflow.
