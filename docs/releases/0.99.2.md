# Ghost FTP 0.99.2 — Releases listing and data-integrity Preview

**Distribution channel:** Preview, not production-certified. The new edition is not considered published until the exact-source CI gates, release asset checks and public index verification all succeed.

## Improvements

- All newly published Ghost FTP versions must appear on [**Releases**](https://github.com/bren-wp/Ghost-FTP/releases). This is the canonical location for Windows, Linux, Android, macOS Preview, source archives and SHA-256 checksum files.
- A post-publication workflow now verifies that the new version is the highest public numeric SemVer and is visible on the first Releases page. It independently checks the source tag, published Preview classification, all required platform assets and their hosted SHA-256 digests.
- README navigates to the permanent Releases page instead of linking to a version that becomes obsolete after the next publication. Older releases and tags are retained.
- Platform versioning is synchronized to 0.99.2, preserving application identifiers and user data migration paths.
- Full dead-code/security audits and cross-platform build, installation and protocol checks remain mandatory.

## Known limitations and not-yet-verified acceptance

- Native macOS FTPS and SFTP secure sessions are not implemented; selections must fail closed without falling back to plaintext FTP.
- The macOS Preview archive remains development-signed rather than Developer ID notarized.
- Android production APK/AAB signing, Windows Authenticode, all real-hardware installations and upgrade preservation remain unverified.
- Complete physical >4 GiB content-hash roundtrips, interrupted transfer fault injection, battery/performance benchmarks and pixel-by-pixel acceptance for all 75 reference screens are not certified.

## Release rule

Current Preview sequence: 0.99.2 then 0.99.3 through 0.99.20, followed by 1.0.0 only after separate production sign-off. **Never delete releases or tags.**
