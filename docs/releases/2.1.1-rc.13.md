# Ghost FTP 2.1.1 RC13 — Single-Shell Fidelity

Release date: pending acceptance

RC13 continues the existing Ghost FTP React + TypeScript + Tauri + Rust codebase. It focuses on making the desktop experience feel like one coherent application while moving closer to the supplied Ghost FTP reference screens.

## UI / UX

- Site Manager, Preferences, Transfer Center and About are primary in-app workspace surfaces rather than fixed modal overlays.
- New Connection and File Properties remain transient in-app panels because they are short, focused tasks in the supplied reference design.
- Backdrop clicks no longer dismiss New Connection or File Properties accidentally; close, Cancel and Escape remain explicit paths.
- Primary workspace switching no longer shows a full-screen modal loading flash.
- Responsive rules explicitly contain titlebar actions, Site Manager columns, Preferences actions and transient-dialog buttons so controls do not overlap.
- Critical production surfaces retain transform-free compositor behavior to reduce WebView2 / GTK raster flicker.

## Click behavior

- The focused file pane publishes its current capabilities to the global toolbar.
- Delete, Rename and Properties are disabled when no valid item is selected.
- New Folder is disabled when the active pane/backend cannot create directories.
- Upload and Download are disabled when their source pane has no selected items.
- Menus keep keyboard navigation, Escape handling and desktop-style hover switching.
- A CI UI contract rejects primary-view modal regressions, browser popup/new-tab navigation and critical buttons without an explicit action contract.

## Protocol and data integrity

RC13 preserves the real FTP, explicit FTPS and SFTP backends from RC12. Production UI must never seed fake servers, fake transfers, fake progress or fake Connected state.

## Acceptance gates

RC13 must not be published until the exact candidate commit passes:

1. Ghost FTP quality workflow.
2. Real FTP / explicit FTPS / SFTP E2E.
3. Native Windows x64 build and native-window QA evidence.
4. Native Linux x86-64 build.
5. Manual/native visual review against the supplied Main, Site Manager, New Connection, Preferences, Transfer Center, File Properties and About references.

RC13 is not FINAL and does not claim pixel-perfect acceptance until the native visual review is completed.
