# Ghost FTP 0.95.27 — bounded FTP recursive directory deletion (development preview)

Published predecessor: [v0.95.26](https://github.com/bren-wp/Ghost-FTP/releases/tag/v0.95.26). The published v0.95.26 tag and assets are immutable.

## Windows/Linux changes

- FTP and explicit FTPS recursive delete builds a complete file/directory inventory before sending DELE/RMD.
- Reject trees exceeding 25,000 entries, 64 nested directory levels or 8 MiB total entry-path bytes.
- Reject duplicate paths and unsupported or ambiguous LIST responses; require verified hidden-file listing support.
- Preserve existing bottom-up deletion order for valid trees.
- Add Rust regressions for realistic hidden-file trees, duplicate entries, malformed replies, runaway nesting, oversized inventories and LIST option failure.
- Advance Rust, Tauri, npm, Go, updater and Android version metadata to 0.95.27 without Android/macOS feature claims.
