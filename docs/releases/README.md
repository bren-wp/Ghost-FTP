# Ghost FTP Release Records

This directory contains two classes of records.

## Canonical release notes

Files named `0.x.y.md` describe the canonical semantic-version history. GitHub Releases is the authoritative source for published binaries/assets.

Current state:

- latest published: **0.16.0**
- active development: **0.17.0**

## Historical legacy records

Files named `2.1.1-rc.*.md` are retained only as historical snapshots from the pre-migration naming scheme.

They are **not** current version numbers, current release instructions or current artifact naming guidance.

The verified mapping/provenance for actually published migrated releases is stored in `version-map.json`.

Use [VERSIONING.md](VERSIONING.md) for the active version policy.
