## Remote Agent detached-job admission hardening

- Check duplicate job IDs and capacity **before** launching commands, under one lock spanning admission, spawn and registration. A rejected request cannot start a child process.
- Allow at most **32 active detached jobs per paired-controller namespace**, with a **256 tracked-job global ceiling**. Deny new starts when no safe capacity is available.
- Never evict or overwrite a running job. When global storage fills, reclaim the oldest completed entry; if spawning fails, admission does not consume a slot.
- Add negative tests for duplicate IDs, controller quotas, global saturation, completed-job reclaim and simultaneous starts of the same identifier.
