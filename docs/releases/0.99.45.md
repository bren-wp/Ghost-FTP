## Security / privacy fix

The desktop diagnostic text redactor formerly stopped at an escaped quotation mark when handling quoted secret values. For example, a malformed or escaped JSON `client_secret` field could have exposed the suffix of a credential in an error toast or log.

- Recognize escaped quotes and backslashes in quoted JSON credentials, standalone text assignments and CLI options without retaining any part of their quoted values.
- When a secret starts with a quote but the closing quote is missing, redact the remaining diagnostic text rather than revealing a suffix.
- Add explicit regressions for OAuth and password patterns, multiple JSON secrets, escaped and unterminated values.
- Retain complete redaction of signed cloud URLs, redaction before diagnostic-length truncation and the existing maximum 64 KiB diagnostic size.
