# Ghost FTP 0.95.14 — Clearer cloud controls and safer cancellation

Move important files with a focused interface and better transfer feedback.

## Improvements
- Signed cloud object upload and download actions are disabled during an active transfer or document selection and re-enabled when the operation ends.
- Recheck cancellation after every blocking stream read, before passing returned bytes to the output or integrity calculations.
- Added Android on-device interaction checks for cloud action availability and invalid private signed-link rejection, and a JVM regression for cancellation during read.
- README retains seven real, release-proven Windows captures, without substituting generated previews.
- Aligned Windows, Linux, Android, Rust, Go and updater metadata for the 0.95.14 release cycle.

## Acceptance remains necessary
- All six exact-SHA GitHub Actions workflows must pass before merging; production packaging must be verified after merge.
- Android SAF lifecycle, real-device cancellation and incomplete-output recovery still need provider-level proof (issue #127).
- Android/macOS vendor OAuth account browsing is not yet available (issue #128).
- 75-reference-screen pixel parity and exhaustive function-level dead-code removal remain unverified; source-file reachability is not sufficient proof.
- Android production signing and store approval remain external steps. macOS Preview is not Developer ID signed or notarized.
