# Ghost FTP 0.99.52 Preview — safer SSH terminal lifecycle

**Author:** BRENDIGO — https://brendigo.com  
**Previous published:** v0.99.51 Preview  
**Channel:** Preview, not certified stable. Exact-source CI and native release checks must pass before publication.

## Corrections

- Atomically reserve one of 32 SSH terminal slots before remote channel setup.
- Release stale PTY map entries after remote EOF/termination and free the semaphore slot when the task ends.
- Preserve SSH exit status and send only one terminal exit event per session.
- Stop holding the session map mutex across async input and resize sends.
- Add a regression test for terminal capacity exhaustion and release.
