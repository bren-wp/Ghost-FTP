# Ghost FTP 0.99.0 — Preview release

**Release state:** development source until six exact-commit CI gate families pass and the automated GitHub Release contains verified SHA-256 assets. **Channel:** Preview; not stable/FINAL.

## Changes
- Begin owner-approved source train 0.99.0 → 0.99.1 → … → 0.99.20 → 1.0.0.
- Remove automated release/tag cleanup. Existing ten surviving releases and all future editions remain public and immutable. No further release or tag deletion is authorized.
- Sync all Windows, Linux, Android, macOS, CLI and source metadata without changing product identity or user storage migration lineage.
- macOS FTP checks the server-declared binary SIZE for each download and verifies exact received bytes before installing a local file; uploads check the post-STOR remote size as well. This is a byte-count integrity check, **not a cryptographic content hash**, and it cannot guarantee a race-free no-overwrite without server support.
- All seven README screenshots now originate from genuine published Windows v0.95.53 QA run 39506868388, source 27a3f841..., with individual SHA-256 pins and no fabricated pixels.
- Expand live/installed-app, secure transport, integrity and source audit coverage as code changes land.

## Acceptance not yet demonstrated
- macOS FTPS requires real hostname-validated TLS for control/data channels and negative certificate tests; SFTP requires SSH host-key verification and authenticated real transfers. Plain FTP is not an encrypted fallback.
- Windows Authenticode, macOS Developer ID notarization, Android Play signing and data-preserving upgrade on physical devices.
- Full 75-screen interactive UI/UX comparison, big-file end-to-end checksums, crash fault injection, Fedora installation, long-run performance evidence.
