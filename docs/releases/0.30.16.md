# Ghost FTP 0.30.16 — premium panel color contract

This release follows v0.30.15 and preserves the 75-screen mapping, existing protocol features, macOS privacy hardening, and Android launcher branding.

## Real cross-platform code changes
- Windows/Linux (React/Tauri): the live primary sidebar consumes the theme-aware semantic panel token instead of a divergent hard-coded navy value.
- Android (Kotlin): rows and input backgrounds now reuse existing canonical Brand.panel and Brand.background colors; no network or credential behavior changes.
- macOS (SwiftUI): the actual sidebar color is corrected from RGB (12,24,43) to the exact approved #0D192B / RGB (13,25,43).
- CI: exact-head branding assertions prevent these cross-platform deviations from recurring.

## Acceptance limitations
This is a scoped visual bugfix, not a claim that all 75 supplied reference screens were verified pixel-for-pixel. MacOS mockups are not included in the ZIP. macOS FTPS/SFTP file operations remain blocked pending trustworthy TLS certificate/hostname and SSH host-key verification; the macOS bundle is not notarized.

## Required publication checks
All six mandatory exact-head workflows, installation artifacts, Preview packages, and SHA-256 release integrity checks must pass before publication. This document does not establish that a release exists.
