# Ghost FTP 0.99.44 Preview — reliable recurring transfer start dates

**Author:** Brendigo — https://brendigo.com  
**Previous published release:** v0.99.43 Preview

## Windows / Linux transfer scheduling

- Fix recurring daily and weekly transfer schedules whose anchor date falls on a spring daylight-saving gap (e.g. 29 March 2026 at 02:30 in Europe/Zagreb). The nonexistent starting occurrence is skipped, and subsequent valid scheduled dates retain the chosen wall-clock time/weekday rather than disabling the entire recurring schedule.
- One-time transfers remain rejected when their start date/time does not exist. Earlier dates and invalid 24-hour times remain invalid.
- Keep no-concurrent-retry guards, last-run deduplication, resume/online/focus wake checks, transfer queue safety, existing credential redaction and direct-to-Files startup.
- Regression coverage exercises daily, weekly and once variants around the spring DST boundary and preserves existing fall DST tests.
