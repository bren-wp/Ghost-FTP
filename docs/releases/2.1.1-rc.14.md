# Ghost FTP 2.1.1 RC14 — UI Fidelity and Click-Contract Polish

Release date: 21 September 2026

RC14 continues the existing Ghost FTP React + TypeScript + Tauri + Rust desktop codebase after RC13. It is a focused production-polish release: native visual acceptance is stricter, critical controls surface backend failures instead of failing silently, and the seven supplied Ghost FTP reference views receive another fidelity pass.

## UI / UX

- Preferences General now follows the supplied reference hierarchy: Language + Appearance, Performance + Transfers, Connection + Security & Privacy, Updates + Integrations.
- Transfer Center reserves substantially more desktop space for the real transfer table/empty state while keeping the real bandwidth, scheduler and log panels visible.
- The Transfer Center More menu now supports initial focus, Arrow Up/Down, Home/End and Escape focus return.
- Standalone and primary window controls surface native-operation failures rather than swallowing them.
- File Manager and tool clipboard actions surface clipboard permission/runtime failures instead of reporting success unconditionally.
- Site Manager export uses a native Save dialog and a Rust export command rather than a browser download shim.

## Real actions and data integrity

- Site export writes the persisted profile metadata through the native backend and does not export credentials stored in the OS keychain.
- Transfer enqueue failures are reported per item instead of disappearing inside empty Promise catches.
- File Browser picker, upload and download queue failures remain visible to the user.
- Preference persistence and live transfer-engine configuration failures are surfaced.
- No example servers, fake Connected state, fake transfers, fake speeds, fake progress or seeded reference files are added.

## Native visual acceptance

RC14 hardens the seven-view Windows QA gate. A PNG is no longer accepted merely because it decodes and contains anti-aliased border colors. The gate now checks decoded dimensions, opacity, raw and quantized color diversity, luminance range/variance, sampled UI edge density and duplicate screenshot hashes. If PrintWindow captures a structureless WebView2 frame, QA falls back to the real WebView2 compositor surface.

The required views remain:

1. Main File Manager
2. Site Manager
3. New Connection
4. Preferences
5. Transfer Center
6. File Properties & Permissions
7. About / Updates / Help

## Protocol and security

RC14 preserves the real FTP, explicit FTPS and SFTP implementations, protocol E2E suite, credential/keychain handling, official ghostftp.com HTTPS allow-list, capability checks and updater verification configuration.

## Release gates

RC14 is published only from the exact candidate source after Ghost FTP quality, Rust formatting/check/tests/Clippy, real FTP/FTPS/SFTP E2E, Windows native build + seven-view QA, and Linux native build all pass.

RC14 remains a release candidate rather than a final/stable release.
