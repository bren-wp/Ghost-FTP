# Ghost FTP by Brendigo — 0.99.79 Preview

**Status:** development source candidate. Publication requires successful CI on the merged main commit and a public GitHub Release with complete assets. **Previous public release:** [v0.99.78](https://github.com/bren-wp/Ghost-FTP/releases/tag/v0.99.78). **Date:** 22 November 2026.

## Remote Agent background service argument hardening

- Preserve executable and argument boundaries when installing Linux systemd user/system services and Windows logon Scheduled Tasks.
- Quote Linux systemd arguments individually, escaping backslashes, double quotes, percent specifiers and literal dollar signs; correctly preserve configured paths containing whitespace.
- Apply Windows command-line quote and trailing-backslash escaping to task paths and arguments.
- Reject embedded control characters (including newline injection) instead of writing malformed or potentially injected service definitions.
- Add platform-specific quoting regression tests and shared control-character validation tests.

## New operational option

- `ghostftp-agentd service-status` now displays Linux systemd LoadState, ActiveState, SubState and UnitFileState or the Windows Scheduled Task details, without creating a device identity or modifying configuration.
- Linux user-service installation reports inability to create its systemd directory instead of silently ignoring the error. Windows installation reports failure to launch the newly registered task instead of falsely reporting a running agent.

## Transfer Center usability

- A new accessible sort control switches between original list order, newest/oldest, largest first and natural filename ordering (e.g. file2 before file10). This sorts only the on-screen history; it never reorders, restarts or reprioritizes actual transfers.
- Malformed timestamps/sizes are placed last, ties keep stable original order and filters/search remain independent. Unit tests cover sorting and non-mutation.
- Responsive filter controls wrap in smaller native windows rather than hiding transfer actions.

## Fail-closed service lifecycle

- `--help`, `service-status`, `uninstall` and unknown commands no longer initialize or regenerate device identity keys, keeping administrative inspection and cleanup free from configuration side-effects.
- Linux uninstallation now checks that the service exists, requires successful stop/disable before removing the unit, and reports failures to remove the file or reload systemd instead of silently claiming success.

## Live bandwidth visualization

- Replace synthetic zero samples with a truthful no-measurement state, distinguish genuinely measured 0 B/s, and preserve the very first real sample.
- Add clear upload/download rate legends, rolling averages, observed peak, gridlines, latest-value markers, and an accessible chart description. Preserve the compact summary-panel height and expose the selected transfer's progress bar to assistive technology. Never invent network throughput.
- Keep a bounded 48-sample history and reset the display after idle periods so unrelated transfer sessions are not stitched into one continuous timeline.
- Test exact SVG geometry, invalid rates, peaks, averages, history bounds, missing/zero data, and immutability of original backend measurements.

## Disk Usage visualization

- Harden treemap partitioning against extremely large file totals that could overflow JavaScript numeric sums and produce invalid rectangles.
- Skip malformed, infinite, zero and negative child sizes. Paint tiny terminal folders instead of leaving invisible gaps.
- Use bounded high-DPI canvas scaling, rerender when moving between monitors, and show an explicit empty/unmeasurable state.
- Support folder selection with arrow keys/Home/End, Enter/Space drill-down and Shift+F10/ContextMenu actions on the canvas.
- Rank the real scanned children by decreasing size without mutating the backend tree; clamp utilization bars to their truthful 0–100% range with accurate zero and sub-1% labels.
- Let keyboard or mouse activate safe file context actions from the ranked list; no hidden no-op buttons.
- Stack the treemap above the ranked list on narrow Windows/Linux windows; keep both accessible while the header wraps its controls and breadcrumb.

## Verification and limits

Source-level changes and tests are not a substitute for native OS acceptance. Require Rustfmt, workspace tests and Clippy, Windows hardening, FTP/FTPS/SFTP protocol E2E, Windows/Linux native installers, checksums and exact merged-main release provenance. Linux systemd unit syntax checks and real install/start/uninstall trials, plus Windows Scheduled Task argument round-trip tests, remain separate acceptance tasks. Cloud-provider integration, physical fault injection and device-specific credential-vault behavior remain independently unverified.

This is an unsigned Preview candidate, not a signed Stable release. GitHub branch protection remains a repository-administrator responsibility tracked in issue #327.
