# Ghost FTP 0.95.11 — connection review follow-up

**Unpublished development candidate.** Last verified public release: [v0.95.10](https://github.com/bren-wp/Ghost-FTP/releases/tag/v0.95.10), immutable source `a74d0515d74501ef99b7dfd4bcca26f92ecf7d8a`, 21 artifacts.

## Source improvements

- Windows/Linux: Required Username remains accessible on narrow and short Files workspaces; Quick Connect connection status now reports Connecting, Connected, Failed and Disconnected from the actual application store.
- macOS: Opening a saved site from Sites discards the abandoned unsaved New connection draft.
- Android: Restoring a saved site retains its user-selected custom port even if the protocol Spinner callback runs later.
- Privacy: Temporary desktop sessions no longer keep passwords or private-key passphrases in the displayed in-memory Site profile after successful transport establishment.
- QA: Strengthen the premium Files contract to catch regressions in compact layout, saved-site navigation and port preservation.
