# Ghost FTP 0.99.10 — 24-language Android accessibility localization (Preview)

Previous published version: **v0.99.9**. Development source version: **0.99.10**. This is a Preview, not production-stable certification.

## Localization and accessibility
- Add 15 user-visible navigation, site, search and transfer interface labels to Android resource files for all 24 advertised languages. This includes accessible descriptions for icon-only controls and search results.
- Migrate 21 corresponding native Android inline English references to localized `getString(R.string...)` calls. The quantified direct Activity UI debt falls from 144 to 123 occurrences; additional dynamic strings elsewhere remain under audit.
- Extend the Android multilingual CI inventory from 10 to 25 extra localized keys (10 previous, 15 new); preserve the 153-key base dictionaries unchanged and keep the native app responsive on small devices.
- Security-sensitive protocol vocabulary, file names, user data and server paths must remain untranslated.

## Gates and remaining limitations
- Required: exact-SHA Android lint/unit/emulator tests, Rust/Windows/Linux/macOS build and security tests, real FTP/FTPS/SFTP E2E, source/release metadata parity, and artifact checks.
- Do not assert every Android or native macOS text is translated. Full locale QA, screenshots on real devices, Android production signing, and macOS developer notarization remain separate acceptance requirements.
- Native macOS FTPS/SFTP identity-verified implementation remains blocked under issue #223 and must not be labeled complete.
