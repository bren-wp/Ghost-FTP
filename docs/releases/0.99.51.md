## Security and correctness

- Shopify, HubSpot and Dynamics 365 authorized requests now use a strict configured-origin URL guard before attaching tokens. API-returned HubSpot task-status links are not trusted as arbitrary bearer destinations; cross-host, HTTPS-downgrade and URL-userinfo attempts are refused.
- Redirects are disabled on these credential-bearing HTTP clients, preventing custom Shopify authorization headers or HubSpot bearer tokens from being forwarded to a redirect target.
- Shared HTTP rate-limit retry logic repeats safe reads (GET/HEAD/OPTIONS) only, not POST/PUT/PATCH/DELETE. Provider 429 or 5xx responses cannot silently re-submit ambiguous writes, folder creation or deletion. Clients retain their explicit error states so users can inspect and safely retry.
- Shopify/Dynamics client-credential token-cache lifetime is capped at one day even if a provider reports u64::MAX, and blank access tokens are rejected.
- Add regressions for Dynamics OData nextLink origin validation, unauthenticated write replay prevention, wrong-origin URLs, bounded token expiry, safe method classification and an actual local HTTP 503 response to a single POST.

## Performance and experience

- Transfer Center's newest-log selector keeps at most the requested number of history entries. For its default 12 rows, selection avoids sorting/copying the full history on each progress refresh, while preserving queue order and transfer object identity. Tests include equal timestamps, 10k transfers and invalid limits.
- README retains seven genuine historical Windows captures and seven verified Linux captures, while also linking genuine v0.99.50 QA artifacts for both platforms. No generated or fabricated images are included.
