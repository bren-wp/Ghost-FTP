# Ghost FTP 0.99.53 Preview — robust Linux credential helper I/O

**Author/publisher:** BRENDIGO — https://brendigo.com  
**Previous published:** v0.99.52 Preview  
**Channel:** Preview, not certified stable. Publish only after exact-source native and security gates pass.

## Changes

- Keep Linux Secret Service child timeout effective while writing credential bytes even if the stdin pipe becomes full.
- Drain helper stdout and stderr concurrently and enforce bounded response allocations.
- Preserve credential write verification, secret length checks, legacy keyutils migration and fail-closed behavior.
- Add regression tests for stalled input, clean stdin closure and oversized output.
- Document scope and remaining risks in [the phase 1–3 audit](../audits/LINUX_SECRET_SERVICE_IO_0.99.53.md).
