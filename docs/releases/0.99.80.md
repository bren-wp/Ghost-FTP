# Ghost FTP by Brendigo — 0.99.80 Preview

**Status:** development candidate, not published. Merge and GitHub Release require green exact-commit Windows/Linux, Rust, frontend, installer, security and protocol checks. **Previous public release:** [v0.99.79](https://github.com/bren-wp/Ghost-FTP/releases/tag/v0.99.79). **Date:** 23 November 2026.

## Dependency maintenance and cross-platform assurance

- Keep the version train, Cargo.lock, npm lockfile, Rust crates, binary metadata, in-app version, updater template and installer metadata synchronized.
- Dependabot dependency-version pull requests were disabled by removing `.github/dependabot.yml`, after a burst of dependency PRs contributed to an overloaded GitHub Actions queue. Dependency updates are reviewed and tested manually; no automated dependency PR scheduler is configured in repository source.
- A one-time compatible npm dependency refresh was completed and tested before merging. Its temporary automatic-commit workflow is removed; future updates must be explicit and reviewed with regenerated lockfiles, TypeScript/UI/transfer and Windows/Linux native gates.
- Check locked dependency consistency on both target platforms; preserve signed-update protections, rollback prohibition, and Windows/Linux installer acceptance.

## Deliberate migration boundaries

- React 19, TypeScript 7, and Tauri 2.12 have newer stable releases than the source baseline. Major updates need a separate migration with regenerated lockfiles, source/API compatibility review, and actual Windows/Linux native CI before they can be considered complete.
- Existing Rust core is pinned to a security-reviewed version; updating Cargo manifests without a reproducible Cargo.lock is forbidden.
- npm registry or Cargo release pages alone cannot prove runtime compatibility, visual 1:1 parity, native credential-store behavior, cloud integration or interrupted-transfer safety.

## Unpublished release recovery

The v0.99.80 source was merged after all PR checks passed, but the main native-build release promotion remained queued. The published version must be verified on GitHub Releases; a green build is not proof of publication. This same-version repair removes the dependency-update PR scheduler and keeps immutable release-lineage checks. No security or publish gates are disabled to force a release.

## Required release gates

npm ci, npm audit, TypeScript, frontend build, product and UI tests, Rust fmt/clippy/tests, cross-platform native bundles, Windows NSIS/MSI install/uninstall smoke, Linux AppImage/DEB/RPM checks, real FTP/FTPS/SFTP and Windows roundtrip tests. Remain **Preview** until all automated CI gates and manual acceptance evidence are available.
