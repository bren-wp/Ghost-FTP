# Ghost FTP 2.1.1 RC9

**More Than Transfer. Total Control.**

RC9 is a native Windows/Linux release-candidate focused on repository cleanup, release reliability, visual parity and documentation quality.

## Highlights

- Keeps the production GUI on the native React + Tauri + Rust path — no browser-host `127.0.0.1` shell.
- Preserves the approved 1290×852 Ghost FTP desktop geometry with real components and adaptive behavior for smaller windows.
- Uses the approved Ghost FTP brand media in the repository README and documentation.
- Cleans duplicated documentation out of the repository root and groups engineering material under `docs/`.
- Removes obsolete RC7/RC8 release automation and replaces it with one RC9 release workflow.
- Tightens source auditing with frontend, Go and Rust checks.
- Removes an unused Rust service constant and redundant default dark-theme token block.
- Aligns the default Ghost FTP accent/text tokens more closely with the approved Electric Blue / Ice White palette.
- Uses clearer, platform-first release filenames without renaming runtime-critical source paths.

## Visual contract

The approved images in `docs/assets/screenshots/` are QA references only. The app must remain real DOM/Tauri UI, not a screenshot background or hotspot map.

Canonical main-window segmentation remains:

- 51 px custom titlebar
- 42 px application menu
- 50 px Quick Connect row
- 62 px toolbar
- 216 px Sites rail
- 416 px file workspace
- 191 px transfer/log area
- 40 px status bar

New Connection remains targeted at 752×628 and File Properties at 530×770 within the available viewport.

## Release status

RC9 is a **pre-release**, not FINAL. FINAL still requires documented native Windows 10/11 titlebar/pixel acceptance, install/upgrade/uninstall acceptance and real FTP/FTPS/SFTP end-to-end transfer evidence.
