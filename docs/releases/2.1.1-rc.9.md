# Ghost FTP 2.1.1 RC9

**More Than Transfer. Total Control.**

RC9 is a Windows/Linux release candidate focused on product branding, repository organization, code correctness, release reliability and tighter UI/UX parity.

## Highlights

- Reorganized source roots as `ghostftp-desktop/`, `ghostftp-runtime/`, `ghostftp-installer/`, `ghostftp-web/` and `ghostftp-updates/`.
- Reduced framework-first naming from public/project-facing paths while retaining only technically required internal names.
- Rebuilt the repository README as a marketing/product landing page with local Ghost FTP logo, icons and approved visual references.
- Renamed visual QA/reference assets with GhostFTP-first filenames.
- Added a dedicated naming policy and a consolidated implemented-vs-next-work project status document.
- Fixed PATH integration migration handling for historical `Ghost FTP` vs `GhostFTP` app-directory names.
- Kept the production GUI on the native Ghost FTP desktop path — no browser-host `127.0.0.1` shell.
- Preserved the approved 1290×852 desktop reference geometry and adaptive smaller-window behavior.
- Fixed Transfer Queue terminal-state actions and active/history separation.
- Added Retry All for failed transfers.
- Added semantic progress controls and reduced-motion handling.
- Expanded Preferences with browser layout, hidden files, remote previews, bandwidth limit, default download folder and editor controls.
- Strengthened CI with TypeScript production build, Go tests/vet, Rust formatting/check/tests and Clippy.
- Improved website local SVG icon use and timer/accessibility behavior.

RC9 is a **pre-release**, not FINAL. FINAL still requires documented Windows titlebar/pixel acceptance, Windows installer lifecycle acceptance and real FTP/FTPS/SFTP end-to-end transfer evidence.
