# Ghost FTP 0.99.15 — Android filename search hardening (Preview)

**Previous public release:** v0.99.14. **Active development source:** 0.99.15 Preview.

## Changes
- Replace wildcard-to-regex compilation in Android local and remote filename search with bounded `FilenameGlob` matching.
- Preserve `*` and `?`, case sensitivity, 80-character query limits, background local search, path and symlink restrictions, and cancellation of stale requests.
- Add JVM regression tests for literal regex metacharacters, Unicode/case behavior and pathological wildcard patterns.
- Update cross-platform version metadata and document remaining acceptance limits.

## Gates
- Run exact-source Android lint/JVM/emulator, Rust, Windows/Linux installers, real FTP/FTPS/SFTP protocol E2E, Swift native macOS, shared macOS ARM/Intel, locale parity, update/signing and release integrity checks before publishing.
- All 75 visual concepts (30 Windows, 29 Linux, 16 Android) still require exact-state captures from installed applications and per-screen measurements; native macOS has no matching concepts.
- Keep native macOS FTPS/SFTP security blocker #223 open. This release remains Preview, not certified production signing.
