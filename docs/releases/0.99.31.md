# Ghost FTP 0.99.31 — Cross-platform security and dead-code audit (Preview)

Previous public edition: [v0.99.30](https://github.com/bren-wp/Ghost-FTP/releases/tag/v0.99.30). Prior tags, assets and source remain immutable.

## Audit scope

Windows/Linux React/TypeScript and Tauri/Rust, Android Kotlin/Gradle, macOS Swift/Keychain/FTP, Go compatibility runtime/installer, build scripts, secret storage, update/release behavior and end-user data safety. Static candidates are not proven dead code; remove only after reachability and compatibility evidence.

## Work in progress

- Conservative source-level and CI dead-code inventory; explicit blocked/untested items.
- Hardening for local API parsing and file permissions and tests for unusual/malformed inputs.
- Exact-head Windows, Linux, Android, macOS, Rust, Go and security CI remain release gates.

## Not certified

Full interactive device coverage, long-lived network fault injection, >4GiB transfers, signing/notarization, offline upgrade/rollback and 75-screen pixel parity need separate real-target acceptance. macOS FTPS/SFTP remain unsupported until validated peer identity verification. Plain FTP is not encrypted.
