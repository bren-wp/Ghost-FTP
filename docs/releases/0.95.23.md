# Ghost FTP v0.95.23 — Android reference UI preview candidate

Published predecessor: [v0.95.22](https://github.com/bren-wp/Ghost-FTP/releases/tag/v0.95.22).

## Native Android changes
- Reusable branded violet/dark reference UI, responsive full-width phone content and 280dp slide-out navigation
- Native interactive Bookmarks screen (reference #10), backed only by real locally stored metadata
- 2-column, eight-action Settings dashboard (reference #15), while legacy working privacy, export, resets and support links stay accessible through Advanced
- Compact About with real on-device version and working official release check (reference #16)
- Three functional General / Advanced / Sync tabs in Add/Edit Site (reference #4); authentic saved site fields loaded for editing with passwords explicitly cleared

## Acceptance policy
This source candidate is a **preview**, not 16/16 finished pixel-perfect release. The supplied two composite reference images are visual targets, not application screenshots or interactive UI. Ghost FTP never uses those images as fake application backgrounds. Every control that appears must have a real handler or honest unavailable state. Android screenshot capture must use a genuine installed debug app at 480x960 with no user credentials. Test current screens against the supplied composites manually before 1:1 status.

## Pre-publication gates
All six exact-head CI workflows must conclude successfully, plus actual Android debug interaction and visual regression comparisons. Preserve previous published release artifacts. Do not publish preview version as stable, re-sign with unverified keys, or claim unsigned AAB ready for Google Play.
