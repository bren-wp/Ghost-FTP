**Previous public release:** v0.99.15. **Development source:** 0.99.16 Preview.

- Add per-channel and exact-image Python regression tests and integrate them into the main quality workflow.
- Carry over the source-tested 0.99.15 Android filename glob hardening without changing its behavior.
- Update Rust/Tauri, Windows/Linux, Android, native/shared macOS, installer, updater and documentation version metadata.
