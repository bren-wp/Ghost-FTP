# Ghost FTP 0.99.60 Preview — safe remote-root downloads

**Publisher:** BRENDIGO · https://brendigo.com  
**Previous canonical release:** v0.99.59 Preview  
**Release channel:** Preview; no independently verified Stable signing.

## Confirmed defect and fix

Recursive directory downloads from remote filesystem root `/` were rejected as invalid: trailing-slash trimming yielded an empty prefix even for a genuine root. The source now permits exactly `/` while maintaining existing absolute-child and per-component path validation.

A new `remote_root_directory_download_keeps_path_validation` test covers allowed root descendants as well as rejected traversal, ambiguous separators, invalid empty/duplicate-slash roots and unsafe local names.
