# Ghost FTP 2.1.1 RC11 — Native

Released: 20 September 2026

**More Than Transfer. Total Control.**

RC11 is a production-fidelity and protocol-integrity release candidate built from the existing React + TypeScript + Tauri + Rust desktop application.

## Highlights

- Production UI geometry rebuilt against the supplied Ghost FTP reference screens.
- Standalone Site Manager, Preferences, Transfer Center and About screens no longer render over the File Manager chrome.
- File/Edit/View/Transfer/Server/Bookmarks/Tools/Help dropdowns are true overlay menus and no longer push the Quick Connect row out of position.
- New Connection no longer reserves a large empty vertical region; it sizes to real content and stays viewport-safe.
- 1290×852 remains the primary reference geometry, with deliberate compaction and component-local scrolling for smaller windows.
- FTP and explicit FTPS use binary transfer mode for byte-safe uploads/downloads.
- Real FTP, explicit FTPS and SFTP E2E remain mandatory release acceptance.
- Quick Connect and Site Manager Test Connection use isolated real backend probes instead of simulated Connected/Disconnected UI state.
- Production dependency audit and native frameless-window architecture checks remain part of CI.

## UI / UX acceptance

RC11 specifically addresses the failure modes visible in the supplied production screenshots:

- no menu rows expanding into normal document flow;
- no menu or toolbar overlap over dialogs;
- no File Manager chrome visible behind full-screen standalone application views;
- no oversized dead region inside New Connection;
- stable custom titlebar/menu/Quick Connect/toolbar stacking;
- consistent Electric Blue / Deep Navy / Slate Blue / Ice White palette;
- modal and panel scrolling contained to the component instead of the whole window;
- responsive compaction without hiding core connection, transfer or file-management actions.

The reference screenshots are visual specifications only. Ghost FTP does not use screenshots, hotspots or click maps as its runtime UI.

## Protocol acceptance

The real protocol CI gate covers:

- FTP login, passive data path, directory operations, upload/download round trip, rename and delete;
- explicit FTPS TLS connection and certificate identity/failure handling;
- SFTP password authentication, encrypted private-key + passphrase authentication, host-key verification, directory operations, chmod, upload/download, rename and delete.

Implicit FTPS is not advertised by RC11.

## Privacy and security

- No required analytics or telemetry.
- Passwords and key passphrases are not intentionally written to normal profile JSON.
- Temporary Quick Connect tests are not saved as profiles.
- Tauri updater signature verification remains configured.
- Production signing requires the protected private signing material to be available to CI; RC11 must not claim signed updater assets if that secret is absent.

## Known limitations / FINAL gates

- RC11 remains a pre-release, not FINAL.
- Persistent native scheduled transfers are not implemented; the UI must not simulate them.
- Implicit FTPS is not claimed.
- Installer clean-install / upgrade / Apps & Features uninstall / reinstall still requires target-machine acceptance evidence.
- Signed updater publication depends on protected signing material being configured in CI.

## UI fidelity correction

The final RC11 UI pass fixes the native production defects visible in the supplied screenshots:

- the main application header/toolbar no longer overlays About, Preferences, Site Manager, Transfer Center or New Connection;
- File/Edit/View/Transfer/Server/Bookmarks/Tools/Help menus are true floating popovers and no longer push the Quick Connect row or toolbar;
- Preferences General restores the intended eight-card reference overview while Terminal and Shortcuts remain available as dedicated functional sections;
- all corrections are implemented in React/CSS/Tauri source; no screenshot background, hotspot map or browser-shell workaround is used.
