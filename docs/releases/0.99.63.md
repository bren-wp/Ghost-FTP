# Ghost FTP v0.99.63 Preview — safe file transfers and persistent profiles

**BRENDIGO** · https://brendigo.com  
**Development version:** 0.99.63 Preview · **Previous published:** v0.99.62 · **Target:** 14 November 2026

## What changed

- **Recursive upload integrity:** symlinks and special files are rejected before any remote directory is created or queued. A symlink to a local private file or external folder is never silently included in an upload.
- **Remote folder errors:** if a remote server rejects `mkdir`, the folder-upload planner accepts it only when listing that existing folder succeeds. Permission and network failures are no longer ignored.
- **Download staging:** failed exclusive temporary-file creation cannot cause cleanup of the pre-existing file/symlink. Failed transfers can clean up their own regular temporary files without deleting linked targets.
- **Saved connection profiles:** added restart persistence tests for connection IDs, hosts, protocol, remote path, auto-connect, favorites, groups and sorting order; saved password/passphrase values remain stored separately in the operating-system vault, not in `profiles.json`.
- **Crash recovery:** if a process exits after moving the old `profiles.json` to a private predecessor snapshot, but before the new primary is installed, the application can load that predecessor read-only rather than discarding it in favor of a stale backup. User-assisted repair is required before further saves.
- **Quality:** Rust regression tests and static source guards for these scenarios; no schema migrations, credential reset or destructive profile modifications.

## Acceptance requirements

Release only after current-HEAD Rust format, check/test/Clippy, frontend production build, whole-source security/dead-code audits, Windows security regression, real FTP/explicit FTPS/SFTP E2E, Windows/Linux native package builds, and immutable Preview release governance all pass. Additional manual validation with real cloud providers and installed-machine updates remains necessary; Preview is **not** a signed Stable release.

Do not delete existing profiles, saved authentication, configuration, stored downloads or published v0.99.62 artifacts.
