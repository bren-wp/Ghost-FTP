# Ghost FTP v0.92.0 — macOS saved-site duplicate discovery

This feature version follows the verified public **v0.91.1** release and narrows one real Windows/Linux-to-macOS parity gap without changing unrelated screen art or transport trust policies.

## New macOS function

- The **Sites** workspace offers a **Possible duplicates** toggle with the number of saved profiles that share a connection endpoint and account.
- Possible matches are tagged in the list; a site edited in the **Files** workspace receives a live advisory while changing protocol, server, port or username.
- Consistent with Windows/Linux, identity compares protocol, trimmed/lowercased DNS host (including a trailing DNS dot), validated port and trimmed **case-sensitive username**. Empty/incomplete host, username or port entries are ignored.
- This is **advisory only**. Never merge/delete/overwrite saved profiles or Keychain credentials, and never connect to the remote host during duplicate inventory.
- Swift XCTest regression coverage exercises identity matching, account case, incomplete sites, grouping and no mutation.
