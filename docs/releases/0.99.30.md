## Changes for review

- Seven real native Linux Tauri/WebKit screenshots from CI: Files, Sites, New Connection, Transfers, Settings, Sync and About. No simulated data or reference artwork is used as screenshots. Require the real app and validate image structure and SHA-256 checksums.
- Linux distro/package matrix for DEB, RPM, AppImage and standalone ELF/tar, added automatically to the notes for each NEW release with compatibility caveats.
- README links genuine Windows screenshots and real Linux evidence; the PR CI can promote seven genuine Linux captures after an exact-source successful native build.
- Shared Windows/Linux connection editor clears unused in-memory passwords and SSH key passphrases on protocol/auth changes, preventing secret reuse when switching to unencrypted FTP.
- Regression checks for screenshot routing, provenance, credentials and distro metadata.

## Pending acceptance
