# Ghost FTP 0.99.9 — Android remote batch-rename collision hardening (development Preview)

Previous published release: **v0.99.8**. Current source train: **0.99.9**. This is a **Preview**, not a production-stable or Apple-notarized claim. GitHub publication requires all exact-head release gates.

## Android: prevent destructive aliases before batch rename
- Compare proposed destination paths with the fresh **full remote directory listing** (both files and directories), rather than file-only case-sensitive string matches. Apply NFC Unicode normalization and locale-independent case folding as a conservative cross-server safeguard.
- Reject duplicate or canonically equivalent selected source paths and malformed paths (dot segments, empty segments, control characters or backslashes) before any protocol write.
- Add regression tests for case-insensitive collisions, NFC/NFD collisions, directory targets, duplicate sources and malformed paths.
- Preserve original user data and stored FTP/FTPS/SFTP profiles. No simulated server states or fake transfer metrics have been added.

## Source and verification gates
- Android lint, JVM unit tests and Android 16 emulator instrumentation must pass for the **0.99.9 source SHA**.
- Recheck the Rust, TypeScript, Go, Windows, Linux, both macOS targets, protocol E2E, dead-code/security scans, packaging and immutable-release checks.
- Existing **Ghost FTP Android UI maketa.png** and **Ghost FTP Android UI Showcase.png** are still the authoritative design references. The sixteen screens are **not yet pixel-certified 1:1**; real-device crash reproduction and real FTP/FTPS/SFTP server acceptance remain open.
- Android Play signing requires owner-held credentials; Apple Developer ID/notarization is not asserted for ad-hoc-signed macOS DMGs. Signed Preview APK, if available, is not the same as a Play production AAB.
