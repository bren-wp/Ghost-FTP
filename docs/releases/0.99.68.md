# Ghost FTP 0.99.68 Preview

**Channel:** Preview (Windows x64 and Linux x86_64). Verify actual publication and downloads at [the canonical GitHub release page](https://github.com/bren-wp/Ghost-FTP/releases/tag/v0.99.68). This source note alone is **not** proof that a release or its assets were published.

## Changes from v0.99.67

- Hardened transfer upload filename validation: reject C0/C1 Unicode control characters, including TAB, ESC and DEL, in addition to path separators. Normal non-ASCII filenames continue to be accepted.
- Added a Rust regression covering the prohibited control codepoint ranges and valid multilingual filenames.
- Corrected operational documentation to distinguish the [published v0.99.67 Preview](https://github.com/bren-wp/Ghost-FTP/releases/tag/v0.99.67) from its earlier candidate description. Added a dated erratum instead of modifying existing release assets, hashes or tags.
- Recorded that `main` lacked branch protection and had no active rulesets on 15 November 2026; enforcement is tracked by [Issue #296](https://github.com/bren-wp/Ghost-FTP/issues/296).
- Introduced the next immutable version train, synchronizing npm, Cargo, Tauri, Windows/Linux Go compatibility tools and updater metadata.

## Security and acceptance limits

This Preview does not guarantee server-independent atomic FTP rename/no-overwrite semantics. Remote staging can persist after a failed transfer. Source-file identity checks are not cryptographic checksums. Automatic cloud mutation retries remain conservative where idempotence is uncertain. FTP without TLS is not encrypted; use verified SFTP or explicit FTPS for sensitive transfers.

Full physical 4+ GiB and 1/4/8 parallel transfer fault injection, Windows Credential Manager and Linux Secret Service after reboot/locked storage, complete cloud-provider live acceptance, Windows 10/11 and Linux X11/Wayland installed-app first-frame/accessibility checks, and publisher signing are **NOT VERIFIED** by source review. Branch protection is **OPEN** until the GitHub ruleset is actually enabled.
