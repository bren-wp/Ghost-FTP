# Ghost FTP 0.30.19 — practical two-pane file manager

This update continues v0.30.18 with functional parity improvements in the real Windows/Linux desktop file manager.

## Implemented
- With an active connection, Upload opens a native OS file chooser when no local files are selected. If local entries are selected, the existing one-click upload behavior remains.
- Single-pane FileBrowser also supports the picker when browsing local files and no local items are selected, uploading to the actual active remote directory.
- Dual-pane FileBrowser now reloads both local and remote file listings after a transfer batch drains, using the same live FilePane reload-token contract as single-pane.
- Added source regression checks for the Upload event bridge, both pane refresh props and selected-vs-picker routing.

## Security
The OS picker is only invoked from a user-facing action on an active connection. Picked files use the existing transfer engine and collision/overwrite workflow. There are no synthetic file listings, demo server credentials or fake transfer progress values.

## Visual acceptance
30 Windows, 29 Linux and 16 Android screenshot concepts are mapped but not fully verified against installed builds. 1:1 remains unaccepted until comparison of actual UI screens and click-by-click behaviors.

## Publication
Release only after all six CI suites are green on identical PR and merged-main commits and canonical artifacts verify.
