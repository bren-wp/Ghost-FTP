# Ghost FTP v0.95.31 — bounded Windows/Linux local directory inventory (development preview)

Published predecessor: [v0.95.30](https://github.com/bren-wp/Ghost-FTP/releases/tag/v0.95.30).

## Changes

- Refuse to publish an incomplete local directory listing once 100,000 entries or 16 MiB cumulative UTF-8 filename bytes would be exceeded.
- Protect file comparisons and sync from treating omitted entries as nonexistent.
- Add Rust tests for boundary enforcement and actual international filename enumeration.
- Preserve current Windows/Linux premium UI and all published v0.95.30 artifacts.
