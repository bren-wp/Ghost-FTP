# Ghost FTP 0.95.1 — development candidate (NOT PUBLISHED)

The latest public release remains **0.95.0**. Do not change immutable public tags or advertise 0.95.1 installation files until all exact-head production gates and release artifact verification pass.

## Implemented in the development branch

- **Issue #131 (partial):** Windows/Linux Settings now uses genuine interactive, keyboard-reachable vertical category navigation at reference-sized desktop windows, with compact horizontal navigation retained at smaller widths. Existing real settings and Sync-only mode remain operational. A Quality contract validates integration and compact-layout rules.
- **Issue #126 (security candidate, pending provider proof):** macOS signed-object PUT/GET now routes through a fail-closed public-address resolver and a peer-bound HTTPS client using macOS system curl with pinned public IPs. TLS uses the original cloud hostname, system certificate trust and no redirection or proxy. The short-lived signed bearer URL is sent via process stdin configuration, not process arguments or telemetry, and never written to configuration files. Invalid private/reserved IP addresses, dangerous URL config characters, mismatched provider checksums and duplicate final HTTP headers are rejected. Tests cover address classes and HTTP header parsing.
- **Issue #127:** GitHub currently reports the SAF issue closed in 0.95.0. Note that physical document-provider, permission-revocation, disk-full and large-file acceptance evidence is still not established by macOS peer-bound transport work.
- **Issue #128:** Vendor OAuth account browsing for Android/macOS remains unimplemented. Signed-object URL support is NOT a Google Drive login or Dropbox/OneDrive account session.
