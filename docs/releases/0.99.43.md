# Ghost FTP 0.99.43 Preview — OAuth diagnostic privacy hardening

**Author:** Brendigo — https://brendigo.com  
**Previous published release:** v0.99.42 Preview  
**Status:** Development candidate; not yet published or production-certified.

## Security fixes

- Redact `client_secret`, `id_token`, `session_token` and `client_assertion` from HTTP query strings, text diagnostics, JSON payloads and command-line arguments.
- Treat cloud URLs containing `X-Amz-Security-Token` as sensitive in full, since their resource paths can also be private.
- Extend the actual shipped diagnostic redactor's regression tests. No real credentials are added.

## Compatibility and retained functionality

- Preserve direct-to-Files startup on Windows/Linux without splash or synthetic delays.
- Keep FTP, FTPS, SFTP, sync, saved connections, transfer queues, native desktop builds and macOS compatibility.
- Full 59-reference visual parity, live provider testing, physical-device installation and production signing remain separate acceptance work.
