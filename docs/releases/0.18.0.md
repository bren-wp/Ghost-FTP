# Ghost FTP 0.18.0

Release status: **development preview — not yet published**

Development date: 27 September 2026

0.18.0 is the next meaningful development cycle after published 0.17.0.

## Changes in this cycle

- Keep README and active documentation imagery pinned to files that are byte-identical to the latest published Ghost FTP release.
- Add CI provenance checks so documentation images cannot silently drift ahead of the latest published release.
- Consolidate duplicate Windows/Linux native build work so one production-native workflow provides both release artifacts and native-window QA evidence.
- Remove obsolete native-preview workflow/references after the canonical release flow consumes the production native build directly.
- Remove hard-coded legacy `v2.1.1-Preview` source-package naming from the active build path.
- Keep exact-SHA quality, protocol, Android and Windows hardening checks around the release build.
- Correct active documentation after the publication of 0.17.0.

## Publication requirements

The exact source intended for `v0.18.0` must pass all active required gates and the canonical release workflow must verify normalized Windows, Linux, Android, source, documentation and SHA-256 assets before publication.

## Stable status

0.18.0 remains part of the pre-1.0 development train. Stable/FINAL promotion remains subject to target-OS lifecycle, visual, security, accessibility and signing acceptance.
