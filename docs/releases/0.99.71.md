# Ghost FTP 0.99.71 Preview — Windows shell and terminal hardening

**Status:** Source candidate until the GitHub release workflow actually publishes this version. Previous public release: [v0.99.70 Preview](https://github.com/bren-wp/Ghost-FTP/releases/tag/v0.99.70), 18 November 2026.

## Windows stability, security and responsiveness

- Replace unqualified `rundll32.exe` launch in the approved external URL command and the edit-in-place file association with the Windows `ShellExecuteW` API. This prevents Ghost FTP itself from resolving a helper executable through a potentially attacker-controlled current directory or PATH.
- Initialize an appropriate COM apartment for the native Shell operation, release it after completion, and run external browser launch on a dedicated blocking worker to avoid unnecessary Tauri GUI stalls.
- Reject oversized or malformed `ghostftp://` protocol-handler URLs before expensive decoding. Bound the total URL to 16 KiB and query parameters to 64, and reject control-character injection, userinfo, URL ports and fragments.
- Decode SSH terminal text across packet boundaries with bounded (at most three incomplete bytes) UTF-8 carry state for stdout and stderr separately; avoid event-loop bias that can starve output under sustained input.
- Add Rust regression tests and negative full-security-audit tests for each critical protection.

## Audits and validation

- Whole-repository conservative dead-code and security static audit remains mandatory. A static or reference-count candidate is NOT proof of safe removal. `npm run check:dead`, TypeScript checks, Go tests/vet, Rust fmt/tests/Clippy, Tauri native builds and genuine FTP/FTPS/SFTP protocol E2E remain mandatory on exact PR SHA.
- Windows Shell/COM opening, native file associations, first-frame GUI, credential-vault persistence, real 4+ GiB transfer fault injection and performance benchmarking require independent native acceptance. Refer to [Windows audit](../audits/WINDOWS_SECURITY_PERFORMANCE_0.99.71.md) and [manual test matrix](../qa/WINDOWS_SHELL_UTF8_ACCEPTANCE_0.99.71.md).
