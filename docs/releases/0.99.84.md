## Recovery verification and performance

- Revalidate the exact live checkpoint and original boot immediately before authorized VM power-off.
- Adaptive Linux helper polling and test-only aggregate vault helper latency (including nearest-rank p95 and p99).
- Streaming benchmark fixtures and byte-for-byte verification; opt-in large file matrix of 100 MiB, 1 GiB and 4 GiB + 1 byte.
- Existing authentication, read-back, recovery integrity, timeout and release guards remain mandatory.

Exact-head compilation, native CI, comparative benchmark results, real VM reset and physical power-loss evidence remain pending. Small sample percentiles are descriptive only. No claim of stable signing or current pixel equivalence is made. See the [recovery lab guide](../../tools/recovery-vm/README.md).
