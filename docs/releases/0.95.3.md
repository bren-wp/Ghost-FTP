## Implemented changes

- **Windows/Linux Transfers:** Four premium overview cards now show *real* live queue totals (all, active/queued, completed, failed) from the existing Rust transfer store. The cards are accessible keyboard-operated filters, with selected-state semantics and a two-column compact layout.
- **macOS Transfers:** Actual credential-free local history powers In progress, Completed, Failed and Cancelled summaries. The cards are descriptive, not fake actions; macOS does not claim desktop queue functionality or unsupported FTPS/SFTP support.
- **Android Transfers:** The Kotlin workspace reports current-session remote-operation outcomes (active, completed, failed, cancelled), reflecting actual running operations. It deliberately does not invent a persistent transfer queue or progress rates.
