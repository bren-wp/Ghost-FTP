# Ghost FTP 0.95.46 — transfer reliability (development Preview)

**Public predecessor:** [v0.95.45](https://github.com/bren-wp/Ghost-FTP/releases/tag/v0.95.45). Keep its tag immutable; this file does not announce or publish a new release.

## Windows and Linux desktop scope

- Dynamic transfer parallelism 1/4/8/16/32: cancel stale shrink debt without aborting running transfers.
- S3-compatible object stores (Amazon S3, Backblaze B2, GCS via object_store): refuse incomplete multipart sources and abort on failure. Cloud account verification remains pending.
- Box upload: use streaming multipart body rather than allocating the entire source file in RAM.
- Google Drive: bounded 32 MiB legacy buffered upload; larger uploads fail safely pending verified resumable API implementation.
- OneDrive session chunks: reject source truncation and short Content-Range.
- No TLS downgrades, SSH host-key bypass, plaintext secrets, or destructive user-data migrations.
