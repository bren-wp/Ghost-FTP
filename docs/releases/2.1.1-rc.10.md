# Ghost FTP 2.1.1 RC10

Released: 20 September 2026

RC10 is the native Windows/Linux release candidate that closes the remaining RC9 CI and native-layout defects found by real build evidence.

## What changed

- Fixed the final Rust Clippy blockers in the standalone Ghost FTP CLI.
- Corrected the native transfer activity band so Transfer Queue and Server Log render as the intended two-column desktop layout instead of collapsing into stacked browser-default blocks.
- Restored explicit grid columns, truncation, action alignment, log layout and overflow behavior for transfer rows.
- Kept compact/mobile fallbacks while preserving the desktop reference geometry.
- Promoted Windows native-window screenshot capture from best-effort evidence to a required build gate and added native window-title validation.
- Carries forward the RC9 startup, Linux PATH integration, Quick Connect, SFTP passphrase, i18n, security, update and release-pipeline hardening.
- Versioned the desktop app, CLI, agent components, compatibility tooling, update preview channel and release artifacts consistently as 2.1.1-rc.10.

## Release status

RC10 is a pre-release candidate. Native Windows/Linux build output, source audit and Windows native-window evidence are release gates. Protocol behavior should still be validated against the target servers and hosting environments used in production before promoting this candidate to a stable FINAL release.
