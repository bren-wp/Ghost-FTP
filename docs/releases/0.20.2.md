# Ghost FTP 0.20.2

Release cycle: **0.20.2 patch release candidate**

Cycle date: 1 October 2026

0.20.2 follows published 0.20.1. This document does not assert publication: only an immutable `v0.20.2` GitHub Release at the verified source SHA with the required assets establishes the release.

## Changes in this cycle

### Android workspace and launch reliability

- Keep Files, Sites, Transfers, Settings and Help & About as separate workspaces behind a persistent left navigation rail instead of one long stacked screen.
- Preserve only the active workspace across Activity recreation; passwords and authenticated session state are still intentionally excluded.
- Scroll the selected workspace into the visible content area so navigation lands on the requested workspace rather than returning to the application header/status area.
- Retain emulator instrumentation that verifies exclusive workspace visibility and click-through navigation.
- Stop treating the human-readable `adb shell am start -W` output format as the launch oracle. Android versions can vary that presentation even when the app launches correctly.
- Prove launch success with the command exit status, the package-specific `RESUMED` Activity state and a live process PID for both the debug test package and installable preview APK.
- Keep lint, APK build, clean install, reinstall, package identity, non-debuggable state, launcher identity and emulator smoke as release blockers.

### Windows and Linux polish retained

- Keep the shared Disconnect action rejection handler so asynchronous disconnect failures are surfaced through the normal redacted error path.
- Keep App, primary sidebar and title bar on one shared workspace resolver to avoid navigation-state drift.
- Retain the 0.20.1 desktop transfer worker-registration/finalization race fix and its regression coverage.

### Version and release integrity

- Advance canonical metadata to 0.20.2 with previous version 0.20.1.
- Advance Android `versionCode` to 211031.
- Keep version tags immutable; the already published `v0.20.1` tag is not reused or retargeted.
- Keep README/documentation screenshots pinned to the newest published release until release-proven replacements exist.

## Publication requirements

The exact source intended for `v0.20.2` must pass Ghost FTP quality, Ghost FTP protocol E2E, Ghost FTP native build, Ghost FTP Android and Validate Windows hardening on the same head SHA.

The canonical release must contain non-empty Windows portable/NSIS/MSI assets, Linux binary/AppImage/DEB/RPM assets, Android validation/installability artifacts, source/documentation archives, native-QA evidence and SHA-256 checksums.

## Stable status

0.20.2 remains in the pre-1.0 version train. Passing automated release gates does not by itself claim 1.0/FINAL product acceptance.
