# Ghost FTP 0.99.14 — 75-screen visual QA audit (development Preview)

**Previous published version:** v0.99.13. **Active source:** 0.99.14 Preview.

## What changed
- Include the offline 75-screen comparison script `tools/qa/compare-screen-references.py` and its documented use with the user-supplied v8 premium reference ZIP, alongside verifiable screenshots of the *installed* application.
- Treat 30 Windows, 29 Linux and 16 Android design references as **concepts**. Require exact screen identity, identical pixel dimensions and measured RGB error before visual acceptance; a render/build success is never proof of pixel-perfect UI.
- Keep mock server credentials, transfers and other illustrative reference state out of real FTP/FTPS/SFTP functionality.

## Validation and limitations
- Required before publication: Rust workspace/Windows hardening, FTP/FTPS/SFTP real protocol tests, Android lint/JVM/emulator, Windows and Linux installer builds, Swift macOS, shared Intel and ARM macOS app packages, localization, image provenance and release SHA/asset gates.
- Full pixel-exact acceptance has **not** been achieved for all 75 screens. Native macOS has no supplied reference mockups; real FTPS/SFTP identity-verified native implementation remains tracked under issue #223.
- Windows/macOS signing and Android Google Play signing are separate production requirements. Release is a Preview, not a stable certified edition.
