## What's new

- Refreshed the public README with clearer product benefits and a complete Windows/Linux download selector.
- Reused genuine application screenshots with historical capture provenance, without presenting mockups as current native screenshots.
- Reworked desktop and installation documentation so Portable EXE, Setup EXE, MSI, AppImage, DEB, RPM and native Linux archives are easy to distinguish.
- Added checks of native file-format headers before release publication. Checksums and archive format checks do not replace identity-verifying code signatures.
- Synchronized the application runtime, installer, package, dependency-lock and updater metadata for a new immutable release candidate.

## Stable readiness

Windows Authenticode, Linux package signing, independent installation/upgrade/rollback validation and real provider acceptance remain separate sign-off requirements. Do not falsely report packages as signed, rename this Preview candidate to Stable or bypass existing release gates.

## Release acceptance

On the exact PR commit, CI must confirm TypeScript and Rust/Go quality, tests, security/dead-code audits, protocol end-to-end coverage, real native Windows/Linux builds, installer smoke and complete nonempty artifact inventories with SHA-256 verification. Publishing occurs only after a separately reviewed merge and all required gates pass.
