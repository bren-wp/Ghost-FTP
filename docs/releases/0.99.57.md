## Stable readiness

Windows Authenticode, Linux package signing, independent installation/upgrade/rollback validation and real provider acceptance remain separate sign-off requirements. Do not falsely report packages as signed, rename this Preview candidate to Stable or bypass existing release gates.

## Release acceptance

On the exact PR commit, CI must confirm TypeScript and Rust/Go quality, tests, security/dead-code audits, protocol end-to-end coverage, real native Windows/Linux builds, installer smoke and complete nonempty artifact inventories with SHA-256 verification. Publishing occurs only after a separately reviewed merge and all required gates pass.

## Post-merge protocol CI repair

- Fix a race in Linux Secret Service subprocess output handling: the bounded stdout/stderr reader previously stopped consuming pipe bytes after the capture limit, potentially closing the pipe early and making an otherwise successful child process fail with SIGPIPE.
- Drain both pipes to EOF using a fixed-size buffer, retaining at most the existing credential/error size limit plus one byte. Overflow detection, timeout and credential redaction behavior remain unchanged.
- Add a regression test for one-megabyte stdout and stderr streams to verify successful helper exit without unbounded retention. This repairs the failed post-merge protocol security gate, without bypassing or disabling it.
