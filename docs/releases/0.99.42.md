GitHub Actions must pass on the exact source SHA: quality/version checks, protocol E2E, native build, Windows hardening and macOS compatibility. Publishing requires a NEW v0.99.42 Preview tag, native packages, SHA256SUMS verification, public release index checks and post-release verification. A merged PR is not sufficient proof of publication.
