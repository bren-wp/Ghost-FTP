# Ghost FTP 0.95.15 — Official help, safer navigation and clearer language

Get help from the official Ghost FTP website without leaving the application with obsolete GitHub issue or legal-document links.

## Improvements
- Windows and Linux, Android and macOS Help/About now open the live, verified HTTPS support, contact, getting-started, privacy and terms pages on ghostftp.com.
- The desktop Rust URL allowlist explicitly grants only approved Ghost FTP paths and the separately labelled GitHub source repository. Tests reject URL lookalikes, query strings, fragments, credentials and unexpected ports.
- Android allows only vetted URLs in its browser launch action. Help and Settings privacy/legal navigation remains accessible.
- Improved visible support and localization contracts, alongside existing FTP, FTPS, SFTP, Android and native build regression gates.

## Acceptance and limitations
- The website's download page currently advertises older packages; direct GitHub release artifacts remain the authoritative, separately linked binaries until web deployment catches up.
- Android and macOS vendor OAuth account browsing (#128), Android real-provider SAF lifecycle safety (#127), full locale natural-language acceptance, 75-screen pixel-exact parity and exhaustive function-level dead-code certification are not proven complete.
- Android Play signing and macOS production notarization remain external acceptance steps.
