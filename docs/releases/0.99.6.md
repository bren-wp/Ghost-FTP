# Ghost FTP 0.99.6 — responsive native Android Preview

**Status:** development Preview, not an accepted production release. Previous verified GitHub version: **v0.99.5**. New publication requires exact-SHA green platform CI plus manual visual and device acceptance.

## Scope

- Responsive layouts across 320x640, 360x800, 393x852 with 1.4x font, 480x960, 720x1280 tablet and 960x540 landscape; correct phone drawer rotation behavior, bounded Files panes, large-font Settings, touch-target-safe footer and keyboard-aware insets.
- Functional remote UTF-8 Text Editor and batch rename, with streaming size caps, remote collision protection and explicit confirmations. No fake files, saved passwords or pretend progress.
- Add Site General visual cleanup; Quick Connect remains accessible in Advanced. Live provider icon vectors preserve pixel clarity at different densities.
- Real Android 16 emulator screenshot and click-through regression inputs: original 480x960 plus additional viewports. These are visual QA evidence, not pixel-perfect reference certification.

## Security and privacy

- Retain FLAG_SECURE, private storage, SFTP fingerprint validation, FTPS hostname verification and staged/backup-preserving uploads.
- Never bundle signing keys. Android release APK and AAB remain unsigned until the documented restricted Play signing workflow; Preview APK uses test-only signing.

## Blockers before production

- Real Android devices, system font and keyboard interactions, lifecycle interruption, physical screen-size coverage and manual comparison to all 16 reference screens have not been fully certified.
- Multi-item durable transfer queue and accurate progress, account-based cloud OAuth and full Sync/Search/Batch options are not complete; do not claim otherwise.
- CI and release artifact digest gates must pass for the final source SHA before merge/promotion.
