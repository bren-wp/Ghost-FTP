# Ghost FTP by Brendigo — 0.99.75 Preview

**Source date:** 22 November 2026. **Previous published edition:** [v0.99.74](https://github.com/bren-wp/Ghost-FTP/releases/tag/v0.99.74). **Status:** not yet published; source development candidate.

## UI, accessibility and safe conflict handling
- The overwrite confirmation action bar adapts to the real 480px minimum desktop window. At 620px and below, Cancel remains separate and all three file decision actions fit a compact row.
- Long, bidirectional, server-controlled filenames wrap, and the full destination path remains inspectable.
- A new explicitly clicked **Copy destination directory path** action uses the clipboard with accessible labeling and success/error feedback. Clipboard failures never appear as success.
- The **Remember my choice** checkbox reveals an accessible warning explaining that the selected overwrite/skip/rename action also affects future conflicts within the current batch, without another prompt.
- Preserve the prior release's per-dialog unique confirmation IDs, safe Cancel, and non-submitting action buttons.

## Transfer Center formatting, telemetry and refactoring

- Extract the transfer row, details, empty state and bandwidth chart into `TransferCenterParts.tsx` while retaining queue state, backend calls, retries and scheduler in `TransferCenterDialog.tsx`.
- Deduplicate progress percentage calculation and reject non-finite, negative transfer counters and rates before showing progress, bandwidth or ETA.
- Show `0 B` for actual empty files rather than an unknown-size dash; show 100% for server-confirmed successful zero-byte transfers, without falsely completing paused or failed transfers. Keep invalid counters as unknown.
- Bound bandwidth graph values before plotting, calculate the peak in one pass without an intermediate allocation and preserve the first genuine bandwidth sample (previously the chart incorrectly displayed two zero samples until the second tick).
- Regression-test the production display functions and the source's peak-value guards as part of `npm run check:ui`.

## Keyboard access and long-path UX

- Transfer rows ignore bubbled Enter/Space keystrokes from their own action buttons, preserving native keyboard operation for Pause/Resume, Retry and Cancel while keeping row-level keyboard selection.
- Truncated local/remote filenames in the row and detail pane expose the full source path in a tooltip and honor text direction.
- Extend regression contracts so this keyboard safeguard cannot be lost during future component refactors.

## Verification and known limitations
- `npm run check:ui` includes a regression file for responsive layout, long names, clipboard action and destructive-default messaging.
- Required acceptance: exact-source TypeScript and frontend build, Windows/Linux native packages, Rust tests/Clippy, Go tooling, Windows hardening, real FTP/FTPS/SFTP SHA-256 integrity tests, canonical SHA-256 asset inventory and publicly verified GitHub Release.
- Native screenshots are QA evidence, not proof of pixel-perfect 1:1 match with approved references. Full OS scaling, non-English locale, external server interoperability, signed Stable distribution and legal review remain separately unverified.
