# Ghost FTP 0.95.26 — FTP command-path control validation (development preview)

Published predecessor: [v0.95.25](https://github.com/bren-wp/Ghost-FTP/releases/tag/v0.95.25). Do not rewrite or retarget the published release.

## Changes

- For Windows/Linux FTP and explicit FTPS, reject empty paths and ASCII control characters before FTP LIST, existence checks, rename, delete, create-directory and SITE CHMOD commands.
- Preserve support for Unicode and ordinary spaces in remote filenames.
- Add source-level Rust regressions covering CR, LF, NUL, TAB, DEL, blank targets and safe Unicode paths.
- Synchronize version metadata for Rust, Tauri, npm, Go and Android build identifiers. Android and macOS behavior is not otherwise changed.
