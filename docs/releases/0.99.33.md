# Ghost FTP 0.99.33 — Windows/Linux unsigned installer readiness (Preview)

**Previously published:** [v0.99.32](https://github.com/bren-wp/Ghost-FTP/releases/tag/v0.99.32). The published tag, source SHA and all release assets are immutable. This new version is not published until exact-head CI and automatic release gates succeed.

## Windows/Linux improvements

- The signed in-app updater no longer displays the false “Ghost FTP is up to date” confirmation when it returns no package; a newer manually downloadable edition may exist.
- Help & About → Updates offers **Open official Windows / Linux downloads**, using only an exact allowlisted GitHub Releases URL. No arbitrary external URLs or unverified package installation.
- The app does not replace a signed update already installed and waiting for restart with a new check.
- Updater failure diagnostics are redacted before logging; a real updater-store regression runs in CI.
- Windows x64 portable EXE, NSIS Setup EXE and MSI, and Linux x86_64 DEB, RPM, AppImage and standalone binaries are regular installable artifacts without requiring a commercial publisher certificate. Automatic updates remain signed-only.

## Verification and upgrading

Download the relevant native package from [official Releases](https://github.com/bren-wp/Ghost-FTP/releases) and the matching `GhostFTP-v<VERSION>-SHA256SUMS.txt`. Verify SHA-256 before running an unsigned binary; an unsigned binary has no publisher identity guarantee. Back up the Ghost FTP profile and keychain state before upgrades and finish transfers before replacing an active installation. Linux Secret Service must be unlocked for password persistence; no plaintext fallback.

Windows and Linux installed-package smoke, Tauri frontend QA, Rust, protocol E2E and SHA-256 artifact checks are release gates; target hardware, Wayland, KDE/GNOME and long-running FTP/SFTP interruption testing remain additional acceptance requirements.

**Release labeling:** The global release train remains Preview while the cross-platform signing/production gates are incomplete. Directly installable unsigned Windows/Linux artifacts are distinct from signed auto-updates and do not independently certify all features as stable on all machines.
