# Ghost FTP 0.95.13 — Privacy, clarity and polished Android branding

Make your next transfer simpler and your privacy choices easier to find.

## What's new
- **Privacy where you expect it:** Android Settings now provides direct, accessible Privacy Policy and Terms of use links, using the existing trusted HTTPS-only destinations.
- **Proudly by Brendigo:** Explicit author credit in Android Settings and Help & About, with localized author labels in every shipped Android language resource.
- **A consistent first impression:** New adaptive launcher icon for Android 8 and later built from the exact existing Ghost FTP mark and colors. The main in-app vector remains unchanged.
- **More natural product copy:** Refined English workspace introductions and the Croatian Settings introduction while preserving the other reviewed translations.
- **Quality gates:** New on-device instrumentation and Android contract checks guard legal-link visibility, attribution and launcher identity. Existing Android 16, Rust, TypeScript, E2E and platform packaging gates remain mandatory.
- **Real marketing imagery:** Repository README continues to show existing captures of the installed Windows app, not concept designs or generated screenshots.

## Downloads
Windows Portable, Setup EXE and MSI; Linux AppImage, DEB, RPM and standalone executable; Android installable Preview APK and unsigned release APK/AAB; macOS Preview ZIP.

## Release and store limitations
Google Play production signing, submission and approval remain separate steps. The production APK/AAB are intentionally unsigned. macOS Preview is not Developer ID signed or notarized and provides plain FTP only. Android SAF cancellation cleanup (issue #127), Android/macOS vendor OAuth account browsing (issue #128), physical-device verification and 75-screen pixel-exact acceptance remain open. Automated source reachability does not prove every individual unused function was deleted.

Previous public release: [v0.95.12](https://github.com/bren-wp/Ghost-FTP/releases/tag/v0.95.12). Its original tag and assets remain immutable.
