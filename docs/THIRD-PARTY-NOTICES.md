# Third-party notices

ByFTP is built with Go and uses operating-system facilities plus command-line networking tools where appropriate. Windows SFTP can rely on the Windows OpenSSH Client feature. Unix FTP/FTPS uses system `curl`; Unix SFTP uses OpenSSH tooling.

Those components are distributed and licensed by their respective vendors or operating-system projects. ByFTP does not bundle third-party credentials or bypass platform licensing requirements.
