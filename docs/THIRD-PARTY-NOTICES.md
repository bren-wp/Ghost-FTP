# Third-party notices

Ghost FTP's active applications are **Windows, Linux and Android**. Optional Chrome, Edge, Firefox and Opera helper ZIPs are companion packages.

## OpenSSH

Desktop SFTP uses the maintained operating-system OpenSSH boundary where configured. Windows typically uses the Windows OpenSSH Client capability; Linux uses distribution-provided OpenSSH tooling.

## Android toolchain

Android is built with the maintained Android/Java toolchain declared by repository configuration and CI.

## Browser helpers

Browser packages use browser extension APIs and local package assets. They do not introduce a second remote-transfer engine.

## Retired Apple dependencies

The previous AppKit/macOS build path and Apple signing/notarization toolchain are no longer part of the active source/release product.

Third-party licenses and notices must be kept current as dependencies change.
