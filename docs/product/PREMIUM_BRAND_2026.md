# Ghost FTP — brand and desktop UI direction

**Publisher:** BRENDIGO · https://brendigo.com  
**Official site:** https://ghostftp.com  
**Platforms:** Windows and Linux desktop

Ghost FTP uses a consistent dark navy and electric-blue visual identity with functional file-management controls, legible typography and responsive dialogs. Historical user-supplied design concepts informed earlier iterations but are not a release acceptance checklist or required screenshot matching target.

## Brand tokens

- Electric blue: `#38ABFF`
- Deep navy: `#0B1E36`
- Slate blue: `#132D52`
- Ice white: `#EAF6FF`

Use the approved production assets for logos, application icons and genuine platform packaging. Preserve actual application behavior; never embed static concept art as a working interface or invent server connections, transferred bytes or user account data.

## Functional UX requirements

- Real Files, Sites, New Connection, Transfer Center, Settings, Sync, Properties and Help actions.
- Responsive windows, keyboard navigation and readable focus indicators.
- High contrast, text scaling and accessible names without hiding essential controls.
- Native titlebar, window management, real filesystem access and safe confirmations for destructive operations.
- Current screenshot galleries must show real source-provenanced application captures.

## Stable release requirement

Visual-reference equality is not an approval gate. Functionality, security, data safety, accessibility, native install/upgrade and integrity proofs remain required. Refer to [desktop QA](../qa/README.md) and [Stable release policy](../release/STABLE_RELEASE_POLICY.md).
