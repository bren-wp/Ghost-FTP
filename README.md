# Ghost FTP Premium

Ghost FTP is a privacy-first desktop FTP / FTPS / SFTP client for Windows and Linux.

This repository is the official source repository for the Ghost FTP project maintained by Brendigo LTD and Brendigo, obrt za programiranje.

Official website: https://ghostftp.com/

> Work in progress: the repository is being populated from the current Ghost FTP 2.1.1 RC line. Native Windows/Linux release builds are only marked final after platform QA passes.
