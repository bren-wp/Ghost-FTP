Security & privacy

Guardrails are part of the interface.

Production signatures

Public Windows releases require trusted Authenticode. Android publication requires the protected production certificate and exact fingerprint verification.

Web SSRF protection

Web FTP blocks private/reserved destinations by default, pins resolved addresses and never treats browser JavaScript as a raw FTP socket.

Ephemeral web credentials

The browser client keeps connection data in page memory and sends it only for the requested HTTPS operation. The supplied web app does not persist connection passwords.
