Privacy

Private by product design.

Ghost FTP does not include application telemetry, behavioral analytics, advertising, fingerprinting or automatic crash uploads in the maintained product surfaces.

Desktop and Android

Connections are made to servers selected by the user. Ghost FTP does not require a Ghost FTP storage cloud. Saved credentials require explicit persistence consent and use platform-appropriate protected local storage where supported.

Web FTP is different

A normal browser cannot directly open FTP, FTPS or SFTP TCP sockets. Therefore /ftp sends the connection parameters you enter over HTTPS to the Ghost FTP web server, which performs the requested server operation. The supplied application does not persist those credentials, does not create accounts and does not maintain transfer history.

Because the web server executes the network request, the hosting operator can technically observe request data at runtime. Deploy Web FTP only on infrastructure you trust and protect the site with HTTPS.

Server logs

The application code does not intentionally write credentials, remote listings or transfer content to application logs. Your web server, reverse proxy, operating system or hosting provider may have independent access/error logging. Configure those systems so request bodies are never logged.
